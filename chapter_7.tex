清晨的医院大厅刚刚亮起叫号屏，挂号、问诊、抽血、拍片、用药和随访已经开始不断产生信息。过去，这些信息大多停留在纸张、胶片和医生经验之中；如今，它们正在进入电子病历、影像系统、监护设备和健康管理平台，并逐渐成为人工智能能够学习和分析的医学数据。

本章围绕医学数据处理与任务类型、医学影像识别与辅助诊断、临床决策分析与健康管理等内容展开介绍，帮助读者理解人工智能为什么能够进入医学场景，以及它在诊疗服务中主要能发挥哪些作用。

\section{医学数据处理与任务类型}

走进医院的一天，可以看到数据几乎伴随每一次诊疗活动产生。患者的主诉写进病历，血常规和生化指标进入检验系统，计算机体层成像（computed tomography, CT）和磁共振成像（magnetic resonance imaging, MRI）图像保存在影像平台，监护仪持续记录心率、血压和血氧，出院后还可能留下随访和康复记录。这些数据共同构成医学判断与医疗决策的重要依据。随着人工智能技术在医学领域的应用不断拓展，了解医学数据的来源、类型、处理流程以及它们与医疗任务之间的关系，成为认识医学人工智能的第一步。

\subsection{医学数据类型与基本特征}

一名患者从入院到出院，可能会留下几十页病历、数百张影像切片、连续监护波形和多次检验结果。医生会把这些资料放在一起理解疾病发生、治疗反应和恢复过程；人工智能则需要把这些资料转化为可以计算的输入，才能从中学习与疾病相关的规律。医学数据通常可以分为电子病历数据、医学影像数据、生理信号数据和生命组学数据等类型。如图9.1所示，不同数据类型在结构形式、信息来源和人工智能处理任务上各有特点，共同支撑疾病识别、病情评估、治疗决策和长期随访等医疗活动。

\subsubsection*{\textbf{1. 电子病历数据}}
门诊医生在电脑中写下患者的主诉、现病史和初步诊断时，一份电子病历就开始形成。电子病历数据是现代医疗信息系统中最基础、最常见的一类数据，主要来源于门诊、住院和随访等临床活动。早期电子病历更多是把纸质病历搬到电脑上，主要解决保存和查阅问题；随着医学信息化不断发展，电子病历已逐渐成为整合患者诊疗全过程的重要平台，记录着从入院评估、检验检查、治疗护理到出院随访的完整轨迹。

电子病历中既包含结构化数据，也包含非结构化文本。结构化数据通常以固定字段保存，例如年龄、性别、体温、血压、检验数值、诊断编码和药物剂量等，计算机可以较容易地进行统计和比较。非结构化文本则主要来自医生书写的病程记录、主诉、现病史、出院小结和随访记录等内容，这些文字更接近真实临床表达，包含丰富的医学判断和诊疗线索。例如，一句“活动后胸闷较前加重，夜间不能平卧”，不仅记录了症状，还隐含了疾病进展和心功能状态变化的信息。人工智能要利用这类文本，通常需要借助自然语言处理（natural language processing, NLP）技术，从中识别症状、疾病、药物、检查、治疗措施和时间关系等关键信息。从内容上看，电子病历通常包括以下几类信息：

\begin{itemize}
\item
  患者基本信息，如姓名、年龄、性别、身高、体重、联系方式等
\item
  主诉、现病史、既往史、个人史和家族史等病史信息
\item
  体格检查结果与临床观察记录
\item
  检验检查结果，如血常规、生化指标、凝血功能等
\item
  诊断、治疗、手术、护理及用药记录
\item
  出院小结、随访记录和康复记录等
\end{itemize}

电子病历的价值在于它能够较完整地呈现患者从就诊到随访的全过程，是临床决策、医疗管理和人工智能文本分析的重要基础。它的难点也很明显：不同医生的书写习惯不完全一致，专业术语和缩略语较多，部分记录结构化程度不高。因此，在人工智能应用中，电子病历往往需要经过整理、提取和规范化处理，才能成为模型可靠学习的材料。

\subsubsection*{\textbf{2. 医学影像数据}}
在影像科工作站前，医生每天要面对大量X线片、CT切片、MRI序列、超声图像和病理图像。医学影像数据能够把人体内部结构、器官形态及部分功能状态转化为可观察的图像，是疾病筛查、病灶发现、范围评估和疗效观察中的重要依据。随着成像设备和成像技术不断进步，医学影像的种类持续丰富，数据规模也迅速增长，因而成为医学人工智能应用最活跃的数据类型之一。常见医学影像数据主要包括：

\begin{itemize}
\item
  X射线成像：X射线成像是临床应用最广泛的基础影像检查方式之一，具有检查速度快、成本较低和设备普及率高等特点。该类影像主要用于骨折筛查、胸部检查以及部分急诊场景中的初步判断。
\item
  数字减影血管造影：数字减影血管造影主要用于显示人体血管结构和血流情况，在脑血管、心血管及外周血管疾病的诊断与介入治疗中具有重要作用。该技术能够较清晰地显示血管狭窄、闭塞、畸形和动脉瘤等病变。
\item
  计算机体层成像：计算机体层成像能够通过断层扫描获得人体内部结构的横断面图像，具有较高的空间分辨率和较强的结构显示能力。该类影像广泛应用于颅脑出血、肺部病变、腹部急症和骨性损伤等疾病的检查与评估。
\item
  磁共振成像：磁共振成像具有软组织分辨能力强、成像信息丰富和无电离辐射等特点，在神经系统、肌骨系统、关节、脊柱及部分肿瘤性疾病的检查中应用广泛。该类影像尤其适合观察软组织病变和复杂解剖结构。
\item
  核医学成像：核医学成像不仅能够反映组织结构，还能够显示代谢活性和功能状态，在肿瘤评估、神经系统疾病和心血管疾病诊断中具有独特价值。PET
  等影像方式常用于病灶定位、分期判断和疗效观察。
\item
  B型超声：B型超声是一种实时、无创、便捷的影像检查方式，广泛用于心脏、腹部、甲状腺、妇产科和血管系统等检查。该类影像能够动态显示器官形态和部分功能变化，在临床中具有较高的实用性。
\item
  各类内镜图像与视频：内镜图像与视频主要通过胃镜、肠镜、支气管镜、腹腔镜等设备获取，能够直接观察人体腔道和器官表面的病变情况。该类数据常用于病灶发现、术中观察、活检定位和治疗过程记录。
\end{itemize}

从数据形式看，医学影像主要表现为图像和视频，具有空间结构信息丰富、视觉特征明显和信息密度高等特点。不同影像技术像是从不同角度观察人体：X射线适合骨性结构和胸部初筛，CT适合断层结构观察和急诊评估，MRI更适合软组织和神经系统检查，超声则具有实时、便捷和无创的优势。不同成像方式的原理和用途不同，后续人工智能处理方法也需要相应调整。

医学影像进入人工智能系统后，常用于病灶识别、异常检测、区域分割、定量测量和辅助诊断等任务。一家大型医院的影像科一天可能产生数万张图像，人工阅片不仅任务繁重，也容易受到疲劳和经验差异影响。人工智能的引入可以在一定程度上提高病灶检出效率，增强影像分析的一致性，并为医生提供直观的辅助信息。

\subsubsection*{\textbf{3. 生理信号数据}}
监护仪屏幕上跳动的曲线，记录的是人体正在发生的变化。生理信号数据是人体生命活动过程中产生并可被采集、记录和分析的信号信息。与电子病历和影像数据相比，生理信号更强调连续性和动态变化，能够反映机体在短时和长时尺度上的状态波动。随着传感器和监测设备的发展，可采集的生理信号种类不断增加，在疾病监测、状态识别和健康管理中的作用也日益突出。常见生理信号数据可以按系统进行划分，例如：

\begin{itemize}
\item
  循环系统生理信号，如心电信号、脉搏波、血压变化等
\item
  呼吸系统生理信号，如呼吸频率、呼吸波形、血氧变化等
\item
  神经系统生理信号，如脑电信号、诱发电位等
\item
  运动系统生理信号，如肌电信号、步态信号和动作感知数据等
\end{itemize}

生理信号通常表现为连续波形或时间序列，具有实时性强、变化快和动态特征明显等特点。心电图可以帮助识别心律失常，脑电图可用于监测神经活动，监护设备连续记录的血氧和呼吸参数则有助于危重患者状态评估。与单次检查结果相比，连续信号更像一段医学录像，能够显示状态如何变化，也能帮助发现短暂但重要的异常事件。

近年来，可穿戴设备的发展使长期生理信号监测从院内延伸到院外。智能手表、动态心电监测设备、睡眠监测设备和运动手环等产品，使心率、睡眠、活动量等信息能够在日常生活中持续记录。对于慢病管理、康复随访和异常预警而言，这类数据让人工智能有机会观察到医院之外的健康变化。

\subsubsection*{\textbf{4. 生命组学数据}}
生命组学数据把医学观察推进到分子层面。医生看到的是症状和检查结果，组学技术则试图追踪疾病背后的基因、蛋白质和代谢物变化。生命组学数据通过高通量测序、质谱分析等技术获得，能够反映机体分子层面的生物信息，在精准医学和个体化治疗中具有重要价值。这类数据通常由仪器自动产生，规模大、维度高、格式相对规范，是现代生物医学研究和临床转化应用的重要基础。生命组学数据主要包括：

\begin{itemize}
\item
  DNA序列数据：DNA序列数据主要反映个体遗传信息的基本组成，是研究基因结构、遗传变异和疾病易感性的基础数据。该类数据常用于遗传性疾病分析、肿瘤突变检测和个体化医学研究。
\item
  蛋白质组学数据：蛋白质组学数据主要描述细胞、组织或机体中蛋白质的种类、丰度及功能状态，能够反映生命活动的实际执行过程。该类数据常用于疾病机制研究、生物标志物发现和治疗靶点分析。
\item
  转录组学数据：转录组学数据主要反映基因在特定条件下的表达情况，即哪些基因被激活以及表达水平高低。该类数据有助于揭示不同组织、不同疾病状态和不同处理条件下的功能变化。
\item
  代谢组学数据：代谢组学数据主要反映机体在生理或病理状态下小分子代谢产物的组成和变化情况，能够较直接地体现生命活动的代谢特征。该类数据常用于疾病诊断、药物作用评价和机体功能状态分析。
\end{itemize}

与传统临床数据相比，生命组学数据更加关注机体内部的分子机制和生物学差异，适用于疾病机制研究、分型分析、靶点发现和个体化干预等场景。基因组数据可用于遗传性疾病分析和肿瘤突变检测，转录组数据可用于观察基因表达状态，蛋白质组学和代谢组学数据有助于揭示疾病相关通路和代谢变化。由于这类数据维度高、变量多、关联关系复杂，机器学习和人工智能方法常被用于其中的模式发现和特征提取。

\subsubsection*{\textbf{5. 医学数据特征}}
把电子病历、影像、生理信号和组学数据放在一起看，会发现医学数据并不是一堆整齐的表格，而更像一组来自不同部门、不同仪器和不同时间点的线索。医学数据首先具有多源异构性。同一患者的数据可能来自门诊问诊、实验室检查、影像检查、手术记录、护理观察、康复训练和院外随访；这些数据有的呈现为数值，有的是自然语言文本，有的是图像或波形，还有一些以时间序列方式连续积累。

医学数据还具有明显的专业性和情境依赖性。同一个数值放在不同患者身上，医学意义可能不同。白细胞计数升高可能提示感染，也可能与炎症反应、应激状态或药物影响有关；相似的影像异常，在不同器官和不同病程中也可能对应不同病理基础。因此，医学数据解释必须结合年龄、症状、既往史、体格检查、用药情况和其他辅助检查综合判断。

疾病不是静止的，医学数据也不应只看一个时点。生命体征的波动、实验室指标的升降、影像复查中的病灶变化以及治疗前后的状态差异，往往比单一数值更能反映病情发展和治疗效果。单次血糖检测只能提示某一时刻的代谢水平，连续血糖监测则能显示血糖变化规律；一次影像检查能反映当前病灶情况，多次复查比较更有助于判断疾病进展、稳定或好转。

医学数据还具有高度敏感性。它直接关联患者身份信息、健康状况、诊疗经过和预后结果，一旦管理不当，可能造成个人隐私泄露，也可能影响医疗秩序和患者权益。因此，医学数据在采集、录入、存储、传输、调用和共享等环节，都需要遵循安全要求、伦理原则和管理规范。

\subsubsection*{\textbf{6. 小结}}

本节介绍了医学数据的主要类型及其基本特征。电子病历、医学影像、生理信号和生命组学数据从不同层面记录人体健康状态，共同构成医学人工智能应用所依赖的数据体系。同时，医学数据具有多源异构、专业性强、动态变化明显和敏感性高等特点。理解这些类型与特征，有助于进一步认识数据处理流程、医疗任务需求和人工智能医学应用方式。

\subsection{数据处理流程与标准规范}

患者从挂号、检查到治疗和随访，每一步都会留下不同形式的数据。电子病历记录诊疗过程，实验室检查保存数值结果，医学影像呈现结构变化，生理监测反映动态状态，随访记录则补充院外恢复情况。这些数据分散在不同系统中，记录方式和组织形式并不完全一致。要让它们进入后续分析、研究和模型训练，就需要经过采集、清洗、标注和标准化处理。数据处理解决的是原始数据如何转化为可用数据的问题，标准规范则解决不同数据如何在统一规则下被记录和使用的问题。如图9.2所示，这些环节共同保证医学数据的完整性、一致性、可用性和可追溯性。

\subsubsection*{\textbf{1. 数据采集}}
急诊室里，一名胸痛患者被推入抢救区。护士记录入院时间，医生询问疼痛部位和持续时间，心电图机开始打印波形，抽血样本被送往检验科，监护仪持续显示心率、血压和血氧，随后患者又接受了胸部CT检查。短短几十分钟内，文字、数值、图像和波形同时产生。这些信息如果只是停留在纸张、设备屏幕或医护人员的口头交接中，就很难被后续分析和利用。数据采集正是医学数据处理的起始环节，它要把诊疗过程中产生的信息准确、完整地记录到相应系统中，使其成为可以保存、识别、调用和分析的数据资源。

数据采集是指在医疗服务、健康监测和医学研究过程中，将患者相关信息按照一定规则记录、传输和保存的过程。在医院内部，数据通常来自电子病历、实验室检查、医学影像、心电图、监护设备、手术麻醉系统和护理记录等；在医院外部，数据还可能来自可穿戴设备、移动健康应用和家庭监测设备。对于人工智能而言，数据采集不是简单地“把资料存下来”，而是决定模型后续能否学习到可靠医学规律的第一步。

一条医学记录能不能发挥价值，往往取决于它是否在正确时间、正确位置被准确保存。患者身份、检查项目、采集时间、设备来源和结果内容之间必须对应清楚。对于急诊胸痛患者而言，症状出现时间、心电图采集时间、抽血时间、肌钙蛋白结果返回时间、首次用药时间和影像检查时间都十分关键。若时间点记录不清，后续模型就难以判断某项指标变化发生在治疗前还是治疗后，也难以评估诊疗措施与患者结局之间的关系。

医学数据采集通常包括几个基本内容。第一是患者基本信息，如年龄、性别、身高、体重、联系方式和就诊编号等，用于确认数据归属和描述患者背景。第二是诊疗过程信息，如主诉、现病史、既往史、诊断、治疗和用药记录，用于呈现疾病发生和处理过程。第三是检查检验信息，如血常规、生化指标、凝血功能、心电图和影像检查结果，用于提供客观医学证据。第四是连续监测信息，如心率、血压、血氧、呼吸频率和血糖变化，用于观察患者状态随时间的波动。第五是随访和院外健康信息，如复诊记录、康复情况、用药依从性和可穿戴设备记录，用于反映患者离院后的长期变化。

随着医院信息化建设不断完善，医学数据采集已经不再依赖单一系统。电子病历系统负责记录诊疗文本和医嘱信息，实验室信息系统（laboratory information system, LIS）负责管理检验申请和检验结果，影像归档与通信系统（picture archiving and communication system, PACS）负责保存和传输医学影像，监护平台负责连续记录生命体征。不同系统共同构成临床数据来源，但也带来了新的问题：同一名患者的数据可能分散在不同平台，不同设备的格式和单位可能不完全一致，不同科室的记录习惯也可能存在差异。因此，数据采集不仅要关注“有没有记录”，还要关注“记录是否规范、是否完整、是否能够对应到同一名患者和同一诊疗阶段”。

在人工智能应用中，采集阶段还需要特别重视数据质量和合规性。若原始数据存在漏记、错记、重复记录或时间顺序混乱，后续再复杂的模型也难以得到可靠结果。若数据采集没有遵循隐私保护和授权要求，模型开发也会面临伦理和安全风险。尤其是涉及身份信息、影像资料、基因检测和连续监测数据时，应明确数据来源、使用目的、访问权限和保存方式。只有在准确采集、规范记录和合规管理的基础上，医学数据才能真正成为人工智能模型学习和临床辅助分析的可靠材料。

\subsubsection*{\textbf{2. 数据清洗}}
在医院信息系统中，同一名患者可能先在急诊完成登记，随后进入住院系统，又在检验系统、影像系统和护理系统中留下多条记录。如果这些记录没有经过整理，可能会出现同一患者信息重复、同一检查项目名称不一致、检验结果缺少单位、部分时间点缺失等问题。对于医生而言，这些问题会影响病情回顾和资料核对；对于人工智能模型而言，它们会破坏数据之间的对应关系，使后续分析结果变得不稳定。因此，医学数据进入标注、分析和建模之前，通常需要先进行数据清洗。

数据清洗（data cleaning）是指对原始数据中的重复、缺失、异常、错误和格式不一致等问题进行识别、核查和处理的过程。它的目标不是简单删除看起来不合理的内容，而是在尽量保持医学信息真实性和完整性的前提下，使数据结构更加清楚、内容更加一致、记录更加可靠。医学数据清洗需要结合临床语境进行判断，因为一些看似异常的记录可能并不是错误，而是真实病情变化的表现。

重复记录是医学数据中较常见的问题。同一患者可能在不同系统中存在相似记录，同一次检查也可能因为系统同步、人工补录或重复上传而出现多份结果。清洗时需要根据患者编号、就诊时间、检查项目、样本编号和报告时间判断这些记录是否真正重复。若重复记录没有被识别，某些样本可能在数据集中被反复计算，从而影响统计结果和模型训练。对于临床研究和人工智能建模而言，重复数据会放大部分患者或部分事件的影响，使模型对真实数据分布产生偏差。

缺失数据也需要谨慎处理。缺失可能来自患者未完成检查、设备采集失败、医生未填写某项内容，也可能来自不同医院信息系统字段设置不一致。处理缺失数据时，不能机械地把所有缺失项都补成平均值。对于身高、体重和部分常规检验指标，可根据研究任务和数据分布采用合理填补方法；对于关键诊断信息、重要时间点或主要结局指标缺失的样本，则可能需要剔除或单独标记。还需要区分“没有记录”和“确实没有发生”。例如，病历中没有记录药物过敏史，并不一定代表患者没有药物过敏史，也可能只是该信息没有被完整填写。

异常值处理更需要结合医学背景。异常值（outlier）是指明显偏离多数数据范围的数值或记录。在一般数据分析中，异常值常被视为需要修正或删除的对象；但在医学场景中，异常值可能代表危急病情。例如，血钾明显升高可能来自样本溶血或录入错误，也可能提示严重电解质紊乱；血氧饱和度明显下降可能是设备脱落造成的假象，也可能反映真实呼吸功能受损。清洗时应结合单位、采集时间、仪器范围、样本状态和临床记录进行判断，确认异常来自录入错误、单位错误、设备噪声，还是患者真实状态变化。

格式统一也是数据清洗的重要内容。不同系统可能用不同方式记录同一概念，例如“男/女”\,“M/F”\,“1/2”都可能用于表示性别；同一项检验可能写作“白细胞计数”\,“WBC”或“白细胞”；血糖单位可能是mmol/L，也可能是mg/dL。如果这些表达没有统一，模型可能把相同医学含义识别为不同变量，也可能把不同单位下的数值错误地放在一起比较。因此，清洗过程中需要统一字段名称、计量单位、时间格式、编码方式和文本表达，使数据能够被准确统计、检索和调用。

不同类型医学数据的清洗重点并不完全相同。病历文本需要处理重复表述、明显错别字、无效模板内容和不规范缩写；检验数据需要核对单位、参考范围、异常值和样本状态；医学影像数据需要检查文件是否完整、图像方向是否正确、扫描参数是否一致，以及是否存在严重伪影；生理信号数据则需要关注信号缺失、噪声干扰、设备脱落和时间戳错误。只有针对不同数据类型采用相应清洗策略，才能减少错误数据对模型的干扰，同时避免误删具有医学价值的信息。

数据清洗不是一次性完成的机械步骤，而是贯穿数据分析全过程的质量控制工作。清洗规则应当记录清楚，包括删除了哪些数据、填补了哪些字段、如何处理异常值、如何统一单位和术语等。若清洗过程缺少记录，后续模型结果将难以追溯，其他研究者也难以复现。医学人工智能依赖高质量数据，而高质量数据需要临床人员、数据管理人员和算法研究人员共同确认其真实性、完整性、规范性和建模适用性。

\subsubsection*{\textbf{3. 数据标注}}
影像科阅片室里，医生在一组肺部CT图像中圈出结节位置和边界，并记录其大小、形态和所在肺叶。对医生来说，这是一项常规阅片工作；对人工智能模型来说，这个被圈出的区域就是一条清晰的学习提示。模型并不知道哪一块阴影值得关注，也不会天然理解“结节”\,“出血点”或“肿瘤区域”的医学含义。只有当医学专家把这些信息标出来，模型才可能在大量样本中学习异常区域与疾病状态之间的关系。

数据标注（data annotation）是依据专业知识对数据内容进行识别、说明和标记的过程。医学数据标注的作用，是把医生、技师或研究人员的专业判断转化为模型能够学习的标签。这里的标签既可以是简单类别，例如“正常”\,“异常”\,“良性”\,“恶性”；也可以是具体区域，例如病灶边界、器官轮廓和细胞核位置；还可以是时间节点，例如心电异常发生时刻、症状出现时间和治疗开始时间。对人工智能而言，标注相当于训练过程中的“答案参考”，它直接影响模型学习方向。

不同类型医学数据的标注内容并不相同。医学影像标注常用于标明病灶位置、边界范围、组织区域和解剖结构。例如，在肺结节检测中，医生可能需要标出结节中心、边界框或完整轮廓；在肿瘤分割中，医生需要区分肿瘤区域、正常组织和周围结构。病历文本标注则主要用于识别症状、诊断、药物、手术操作、治疗措施和时间关系。例如，句子“胸闷较前缓解，继续口服阿司匹林”中既包含症状变化，也包含用药信息。生理信号标注常用于确定异常波形、关键事件和重要时间段，如心律失常片段、癫痫发作片段或血氧下降时间点。生命组学数据的标注则通常与样本来源、疾病分型、治疗反应和预后结局有关。

医学标注并不是简单贴名称，而是一次压缩后的临床判断。同一片模糊阴影可能是真正病灶，也可能只是伪影；同一段心电异常可能具有临床意义，也可能与电极接触不良有关；病历中的“症状改善”需要结合用药时间和病情变化理解。因此，高质量标注通常需要医学专家参与，并在标注前制定统一规则。标注规则应明确标注对象、标注范围、类别定义、边界处理方法和不确定样本处理方式。例如，肺结节边界模糊时应按可见边缘标注，还是按估计边缘标注；多名医生意见不一致时，应采用复核讨论还是多数意见，这些都需要提前规定。

为了提高标注质量，医学数据标注通常需要设置一致性控制。标注一致性是指不同标注人员对同一数据给出相近判断的程度。若同一张图像被两名医生标注出明显不同的病灶范围，模型就难以学习稳定规律。实际工作中，常采用双人标注、专家复核、抽样质检和一致性评价等方式提高标注可靠性。对于关键任务，如肿瘤边界勾画、病理分级和高风险疾病筛查，标注结果往往需要由更有经验的医生复核。这样做虽然增加工作量，但可以减少错误标签对模型训练的影响。

标注形式也会影响模型任务类型。若只有“有病灶”或“无病灶”的类别标签，模型更适合完成图像分类；若提供病灶位置框，模型可以训练目标检测任务；若提供精确边界轮廓，模型可以训练图像分割任务；若提供时间点或事件片段，模型可以用于时序事件识别。标注越精细，模型能够学习的任务越具体，但标注成本也越高。医学影像中逐像素勾画肿瘤边界、数字病理中标注细胞核位置、长程脑电中标注异常发作片段，都需要大量专业时间。因此，实际项目中需要根据研究目标选择合适的标注粒度，而不是一味追求越细越好。

医学数据标注还需要面对不确定性。临床判断并不总是黑白分明，有些病例本身就处于可疑、早期或边界状态。对于这类样本，可以设置“不确定”\,“待复核”或“低置信度”标签，避免强行归入某一类别。部分任务也可以记录多个医生意见，以反映真实临床判断差异。对于人工智能模型而言，这些不确定信息并不是无用内容，它提醒模型开发者注意任务本身的复杂性，也提醒使用者不要把模型输出理解为绝对结论。

数据标注的最终目的，是让医学数据能够进入训练、验证和评价环节。标注后的数据可用于训练模型识别病灶、分类疾病、预测风险和评估疗效，也可用于检验模型输出是否接近专家判断。但标注质量不高时，模型可能学习到错误模式。例如，若肺结节边界标注不一致，分割模型输出会不稳定；若文本中药物名称标注遗漏，自然语言处理模型可能无法准确抽取用药信息；若病理分级标签来自不同标准，模型预测结果就可能难以解释。因此，数据标注是医学人工智能中连接临床知识与模型学习的关键环节，也是决定模型可靠性的基础工作之一。

\subsubsection*{\textbf{4. 数据标准化}}
不同医院对同一项检查的记录方式可能并不一样。一家医院在检验系统中写作“WBC”，另一家医院写作“白细胞计数”，有的报告使用英文缩写，有的报告使用中文全称，单位和参考范围也可能不同。医生在本院工作时，通常能够根据经验理解这些写法；但当数据要在不同系统之间传输、汇总和用于人工智能建模时，这些差异就会成为问题。如果不加整理，计算机可能把同一项医学指标当成多个不同变量，也可能把不同单位下的数值错误地放在一起比较。

数据标准化（data standardization）是指按照统一规则整理数据的术语、格式、单位、编码和记录方式，使不同来源的数据能够被一致理解和使用。它的目的不是简单把表格排整齐，而是让数据在不同医院、不同系统和不同研究任务之间能够正确对应。对于医学人工智能而言，标准化程度越高，模型越容易识别同一医学概念，结果也更容易比较、复核和解释。

医学数据标准化首先体现在术语和项目名称的统一。临床记录中常见同义词、简称和英文缩写并存的情况，例如“白细胞计数”\,“WBC”和“白细胞”可能指向同一类检验项目，“心梗”\,“心肌梗死”和“急性心肌梗死”在不同语境下也可能存在包含关系。若这些名称没有经过统一，系统就难以判断它们是否属于同一医学概念。标准化处理需要尽量采用规范术语和统一命名规则，使病历文本、检验项目、诊断名称和治疗操作能够被系统准确识别。

单位标准化同样重要。医学检验结果离不开计量单位，不同单位下的数值不能直接比较。血糖可以用mmol/L表示，也可以用mg/dL表示；肌酐、胆红素、血脂等指标也可能因地区、系统或实验室习惯不同而采用不同单位。如果只保留数值而忽略单位，人工智能模型可能把完全不同意义的数据混在一起。标准化时应明确每一项指标的单位，并在必要时完成单位换算和参考范围统一。

编码标准化有助于不同系统之间共享和检索医学信息。疾病诊断、手术操作、药物名称和检查项目通常需要对应到相对统一的编码体系。例如，疾病诊断常使用国际疾病分类（International Classification of Diseases, ICD）进行编码，医学影像数据常采用医学数字成像与通信（Digital Imaging and Communications in Medicine, DICOM）格式保存和传输。编码的作用是减少文字表达差异带来的歧义，使同一类医学对象能够在不同系统中被稳定识别。

时间格式和数据结构也需要统一。医学数据往往与时间密切相关，入院时间、发病时间、检查时间、用药时间、手术时间和随访时间都可能影响医学判断。若一个系统采用“年-月-日”格式，另一个系统采用“月/日/年”格式，或者不同记录缺少具体时分信息，模型就难以准确还原诊疗过程。标准化处理应明确时间记录方式，并尽量保留能够支持临床分析的时间粒度。对于连续监测数据，还需要保证采样频率、时间戳和设备来源记录清楚。

不同类型数据的标准化重点并不相同。病历文本需要统一医学术语、缩写和表达方式；检验数据需要统一项目名称、单位、参考范围和异常标记；医学影像数据需要保留成像设备、扫描参数、图像方向、层厚和序列信息；生理信号数据需要明确采样频率、导联信息、设备来源和时间同步方式；生命组学数据则需要统一样本编号、检测平台、数据格式和基因或代谢物命名方式。只有把这些信息整理清楚，后续的数据融合、模型训练和结果解释才有基础。

需要注意的是，数据标准化并不意味着消除所有差异。有些差异本身具有医学意义，例如不同实验室参考范围不同，可能与检测方法和试剂体系有关；不同影像扫描参数不同，可能反映检查目的和患者状态差异。标准化的目标是让数据能够被正确理解，而不是把所有数据强行改成完全一样。因此，在标准化过程中应保留必要的原始信息和转换规则，避免因过度统一而丢失临床背景。

\subsubsection*{\textbf{5. 小结}}
医学数据从原始记录进入人工智能分析，通常要经过采集、清洗、标注和标准化等环节。采集决定信息能否被完整保存，清洗影响数据内容是否准确稳定，标注赋予数据明确的医学指向，标准化则保证不同数据能在统一规则下记录和使用。上述环节前后衔接，共同构成医学数据进入分析、研究和应用过程的基本路径。

\subsection{多源数据融合与表示学习}

急诊接诊一名疑似脑卒中的患者时，医生通常不会只依赖单一检查结果。患者的发病时间、肢体活动情况和既往病史来自问诊记录，头颅CT可以帮助排除脑出血，磁共振成像能够进一步显示缺血范围，血糖、血压和凝血功能等指标会影响治疗方案选择。对医生来说，这些信息需要放在一起综合判断；对人工智能而言，不同来源、不同形式的数据也需要经过整理、对齐和融合，才能形成较完整的患者状态表达。

多源数据融合（multi-source data fusion）是指将来自不同系统、不同设备和不同诊疗环节的数据进行整合分析，使模型能够从多个角度理解同一医学问题。表示学习（representation learning）是指通过模型或算法，把文本、图像、波形和分子变量等原始数据转化为可计算的特征表达。前者解决“多类数据如何联合使用”的问题，后者解决“不同形式的数据如何被模型理解”的问题。二者共同构成医学人工智能处理复杂临床信息的重要基础。为更直观地说明这一过程，可将其概括为数据对齐、表示学习和数据融合三个核心环节，如图9.3所示。

\subsubsection*{\textbf{1. 多源数据类型}}
多源数据是指来自多个数据来源或多个业务环节的数据。在医学场景中，它通常包括电子病历、医学影像、生理信号、生命组学数据和院外健康监测数据等。多模态数据是指具有不同表现形式的数据，例如文本、图像、波形、视频和结构化数值。多源强调数据“来自哪里”，多模态强调数据“以什么形式存在”。两者经常同时出现，但含义并不完全相同。

医学诊疗过程本身就是多源信息共同参与的过程。电子病历记录患者主诉、病史、诊断、治疗和随访情况，医学影像显示器官结构、病灶位置和形态变化，生理信号反映心率、血压、血氧、心电和脑电等动态状态，生命组学数据则从基因、蛋白质和代谢物层面提供分子信息。这些数据来源不同，记录形式也不同，但它们共同指向同一对象，即患者的健康状态和疾病过程。

以肺部感染评估为例，病历文本可以记录发热、咳嗽和咳痰情况，血常规和C反应蛋白（C-reactive protein, CRP）能够反映炎症状态，胸部CT可以显示肺部病变范围，血氧变化则提示呼吸功能是否受到影响。若模型只分析影像，可能难以区分感染、肿瘤或其他肺部异常；若只分析检验指标，也无法判断病变位置和范围。多源数据的价值就在于把不同层面的医学线索联系起来，使人工智能模型获得更接近临床综合判断的信息基础。

\subsubsection*{\textbf{2. 数据对齐处理}}
数据对齐是指将同一患者、同一次就诊或同一疾病阶段的不同数据建立对应关系。医学数据常分散在电子病历系统、检验系统、影像系统和监护设备中，如果患者身份、检查时间和诊疗阶段无法对应，后续融合分析就容易发生错误。

数据对齐通常包括患者身份对齐、时间点对齐、项目名称对齐和诊疗阶段对齐。患者身份对齐用于确认不同系统中的记录属于同一名患者；时间点对齐用于判断某项检查发生在治疗前、治疗中还是治疗后；项目名称对齐用于统一不同系统中的检查名称和记录方式；诊疗阶段对齐则用于区分初诊、复查、住院治疗和出院随访等不同阶段。例如，某名患者在用药前后的两次血糖检测结果，只有明确对应具体时间和治疗阶段，模型才能正确理解血糖变化与治疗干预之间的关系。

\subsubsection*{\textbf{3. 表示学习方法}}
同一名患者的数据可能同时包含病历文本、CT图像、心电波形和基因检测结果。对医生来说，这些资料可以通过医学经验综合理解；对人工智能模型来说，它们必须先转化为可以计算和比较的特征表达。表示学习是人工智能中用于获得数据特征表达的方法。这里的“表示”可以理解为数据在模型中的表达形式，例如文本向量、图像特征图、信号特征序列或分子特征向量。医学数据形式差异很大，表示学习的作用，就是把这些不同形式的数据转化为模型能够处理的输入。

表示学习方法大体可以分为人工特征表示、传统降维表示、深度学习表示和多模态表示等类型。人工特征表示是较早使用的方法，通常由研究者根据专业知识提取具有医学意义的变量。例如，在影像分析中，可以提取病灶大小、边缘规则性、密度、纹理和形状等特征；在生理信号分析中，可以提取心率变异性、波形幅值、频率变化和异常节律等特征；在临床表格数据中，可以直接使用年龄、血压、血糖、血脂和检验指标等变量。这类方法的优点是含义比较清楚，医生较容易理解；不足是依赖人工设计，面对复杂图像、长文本和高维组学数据时，表达能力有限。

传统降维表示常用于变量较多、信息冗余较明显的数据。降维是指在尽量保留主要信息的前提下，将高维数据转化为较少数量的综合特征。主成分分析（principal component analysis, PCA）是常见的降维方法，它可以把多个相关变量压缩成少数综合变量，用于减少冗余和降低模型复杂度。在生命组学数据中，一次检测可能产生上千甚至上万个基因、蛋白质或代谢物变量，若直接进入模型，容易造成噪声干扰和过拟合。通过降维和特征筛选，可以提取更稳定、更便于建模的分子特征。

深度学习表示是当前医学人工智能中常用的方法。它不完全依赖人工设计特征，而是通过神经网络从数据中自动学习有用信息。卷积神经网络（convolutional neural network, CNN）常用于医学影像表示学习，可以从图像中逐层提取边缘、纹理、形态和病灶结构等特征；循环神经网络（recurrent neural network, RNN）及其改进结构可用于心电、脑电和连续监测信号等时间序列数据，帮助模型捕捉随时间变化的规律；Transformer模型适合处理文本和序列信息，可用于病历文本、检查报告和多模态医学数据分析。深度学习表示的优势在于能够自动捕捉复杂模式，但其结果解释难度较高，对数据规模和标注质量也有较高要求。

多模态表示用于处理多种数据形式共同参与的任务。多模态数据可能同时包括病历文本、医学影像、检验指标、生理信号和组学数据。模型通常会先分别提取不同模态的特征，例如从病历中提取症状和诊断信息，从影像中提取病灶结构特征，从检验指标中提取生理状态特征，再将这些特征放入同一分析框架中。以肿瘤诊疗为例，病理类型、影像分期、基因突变和治疗反应可以共同构成患者状态表示，辅助模型进行风险预测或治疗反应评估。多模态表示能够提供更完整的信息，但也更容易受到数据缺失、时间不一致和模态质量差异的影响。

表示学习并不等同于把医学数据机械地变成数字。好的特征表达应尽量保留数据中的医学含义。影像特征应能反映病灶形态和组织结构变化，文本特征应能反映症状、诊断和治疗关系，生理信号特征应能反映动态趋势和异常事件，组学特征应能反映分子层面的疾病差异。若特征表达只捕捉到设备差异、记录习惯或偶然噪声，模型即使在训练数据上表现较好，也可能难以适用于真实临床场景。因此，在医学人工智能中，表示学习既是技术问题，也是医学信息能否被正确表达的问题。

\subsubsection*{\textbf{4. 数据融合方式}}
数据融合方式是指不同来源数据在模型中被整合的具体位置和方法。按照融合发生的位置不同，多源数据融合通常可以分为早期融合、中期融合和晚期融合。早期融合（early fusion）是指在模型分析前将不同来源的数据合并为统一输入，例如把年龄、检验指标、病史特征和部分影像特征整理成同一张特征表。中期融合（intermediate fusion）是指在模型内部分别提取不同数据特征，再将这些特征组合起来。晚期融合（late fusion）是指不同模型分别给出结果后，再综合这些结果形成最终判断。

不同融合方式适合不同任务。结构化临床数据比较完整时，早期融合实现较为直接；医学影像和病历文本共同参与分析时，中期融合更有利于保留不同数据自身特点；当医院中已经存在影像识别模型、风险预测模型和用药提醒模型时，晚期融合更便于整合不同模型输出。可以将这三种方式理解为三个层次：先合并数据，再合并特征，最后合并结果。

实际应用中，融合方式并不是越复杂越好。若数据量较小、缺失较多或标注质量不高，复杂融合模型反而可能增加不稳定性。选择融合方式时，需要同时考虑数据类型、样本规模、临床任务和结果解释需求。

\subsubsection*{\textbf{5. 应用局限}}

多源数据融合能够提供更完整的医学信息，但它并不能自动带来更可靠的结果。首先，不同数据之间可能存在缺失、不一致和时间不同步等问题。患者可能有完整影像资料，却缺少规范病历记录；也可能有连续监测数据，却没有明确诊断标签。其次，不同数据质量差异会影响融合效果。如果某一类数据存在较多噪声或错误标注，模型可能把这些错误信息带入综合判断。

多源融合模型还面临结果解释难的问题。单一影像模型的结果可以回到图像区域进行查看，单一检验指标模型也较容易解释变量影响；但多源融合模型同时使用文本、影像、信号和结构化指标时，医生需要知道哪些数据对最终结果起主要作用。如果模型只给出一个风险分数，却不能说明依据来自影像、检验指标还是病历文本，临床使用时就会受到限制。

\subsubsection*{\textbf{6. 小结}}
本节介绍了多源数据融合与表示学习的基本内容。医学数据来自电子病历、医学影像、生理信号、生命组学和院外监测等多个来源，不同数据从不同层面记录患者状态。多源数据融合通过数据对齐、特征提取和信息整合，使模型能够综合利用多类医学线索；表示学习则把文本、图像、波形和分子变量等不同形式的数据转化为可计算的特征表达。多源融合有助于疾病识别、风险预测、疗效评价和健康管理，但其效果依赖数据质量、时间对应关系和临床解释，不能脱离医学语境单独使用。

\subsection{医疗人工智能的典型任务}

一名患者做完胸部CT后，医生首先想知道图像中是否有异常；发现小结节后，又需要判断它更像良性还是恶性；若患者还有基础病，还要评估未来风险，并考虑下一步检查或治疗方案。医疗人工智能的任务通常由这些医学问题引出。电子病历、医学影像、生理信号和组学数据进入系统后，通常会被组织为病灶识别、辅助诊断、风险预测和治疗决策支持等任务。如图9.4所示，这些任务从数据识别逐步走向诊疗支持。

\subsubsection*{\textbf{1. 病灶识别}}
在影像科阅片时，医生最先要回答的问题往往很直接：图像里有没有异常，异常在哪里。胸部CT中一个几毫米的肺结节，眼底图像中一处细小出血点，病理切片中一片可疑肿瘤区域，都可能成为疾病判断的重要线索。对于医生来说，发现这些异常需要经验、耐心和对影像细节的敏感；对于人工智能来说，病灶识别就是让模型从复杂医学图像中自动寻找异常区域，并把可疑位置以定位框、分割轮廓、热力图或概率评分等形式提示出来。

病灶识别是医疗人工智能中最基础的一类任务，主要目标是在医学影像、病理图像或其他可视化医学数据中发现异常结构、异常区域或疑似病灶。它面向的数据以图像类数据为主，包括X线、CT、MRI、超声、数字病理切片和内镜图像等。这类数据结构复杂，背景组织较多，病灶大小差异明显，有些病灶边界清楚，有些则与正常组织交织在一起。因此，病灶识别模型既要能提取图像特征，也要能判断异常区域的位置和范围。

早期病灶识别主要依赖人工设计特征。人工设计特征是指研究者根据图像特点和医学经验，手动提取灰度、纹理、边缘、形状、密度和统计特征，再交给分类模型进行判断。例如，在乳腺X线图像中，模型可以提取钙化点形态和分布特征；在肺结节识别中，可以提取结节大小、边缘毛刺、密度和形状特征；在病理图像中，可以提取细胞核大小、染色强度和组织排列特征。随后，支持向量机（support vector machine, SVM）、随机森林（random forest, RF）、逻辑回归（logistic regression, LR）或K近邻（k-nearest neighbors, KNN）等方法可用于判断这些区域是否异常。这类方法的优点是特征含义相对清楚，便于解释；不足是特征设计依赖人工经验，面对复杂背景和多样化病灶时表达能力有限。

随着医学图像数据增多和深度学习发展，病灶识别逐渐从人工设计特征转向自动特征学习。卷积神经网络（CNN）是医学图像识别中常用的深度学习模型，它可以从原始图像中逐层学习边缘、纹理、形态和空间结构等特征。浅层网络通常关注边缘和纹理等局部信息，深层网络则更容易形成对病灶形态和整体结构的表达。AlexNet、VGG、ResNet和DenseNet等网络结构曾广泛用于医学图像分类和病灶识别任务，其中残差网络（residual network, ResNet）通过残差连接缓解深层网络训练困难，密集连接网络（densely connected convolutional network, DenseNet）通过特征复用增强信息传递能力。对于非计算机专业读者而言，可以把这些模型理解为不同类型的图像特征提取器，它们的共同目标是从图像中学习与病灶相关的视觉模式。

在实际应用中，病灶识别并不只有“判断有没有病灶”这一种形式。若任务是指出病灶大致位置，常使用目标检测方法。目标检测是指在图像中发现目标位置并用边界框标出区域的方法，常用于肺结节、骨折、出血点和息肉等可疑病灶定位。若任务是精确描绘病灶边界，则常使用图像分割方法。图像分割是指把图像中的器官、组织或病灶区域从背景中划分出来的方法，常用于肿瘤分割、器官分割和病灶体积测量。U-Net是一种常用于医学图像分割的网络结构，它通过编码器提取图像特征，再通过解码器恢复空间细节，适合处理病灶边界勾画和器官区域分割等任务。

为了识别小病灶、低对比病灶和复杂背景中的异常区域，模型还常结合多尺度融合和注意力机制。多尺度融合是指同时利用不同大小和不同分辨率的图像特征，使模型既能关注较大的病变范围，也能捕捉细小异常。注意力机制（attention mechanism）则可以让模型在分析图像时更加关注与任务相关的区域，减少正常组织、噪声和背景结构的干扰。例如，在眼底病变筛查中，模型需要关注微血管瘤、出血和渗出等小区域；在病理肿瘤识别中，模型需要从大量组织区域中筛选出更可能与肿瘤相关的局部小块。对于这类任务，单纯依赖整张图像分类往往不够，模型需要具备更细致的定位和区域分析能力。

一个病灶识别模型从建立到输出结果，通常需要经过数据采集、图像标注、质量筛查、预处理、特征学习、模型训练和结果展示等步骤。图像标注是其中非常关键的环节，医生或专业标注人员需要在图像中标出病灶位置、边界或类别，为模型学习提供参考。预处理通常包括图像去噪、尺寸调整、灰度归一化、伪影处理和感兴趣区域提取等操作。模型训练完成后，系统可以输出可疑区域、边界框、分割轮廓、热力图或风险概率。医生再根据这些提示回到原始图像中复核，判断模型提示是否符合真实病变表现。

病灶识别在临床筛查和辅助诊断中具有较多应用。肺结节检测可以帮助医生在大量胸部CT切片中快速发现可疑小结节；眼底病变筛查可以从眼底照相图像中提示出血、渗出和微血管瘤等异常；数字病理分析可以辅助定位肿瘤区域或异常细胞聚集区；内镜图像识别可以提示息肉、溃疡或可疑肿瘤区域。这些应用的共同特点是图像数量多、阅片工作量大、病灶可能较小或容易被背景干扰。人工智能可以提高筛查效率，但它给出的结果仍应作为辅助信息，而不是最终诊断结论。

病灶识别也存在明显局限。不同医院的成像设备、扫描参数、图像质量和标注标准可能不同，模型在一个数据集上表现较好，并不代表能直接适用于所有临床场景。小病灶、边界模糊病灶、罕见病灶和多病共存情况仍可能造成漏检或误检。样本不平衡也是常见问题，即正常图像或常见病灶数量远多于少见病灶，模型可能更容易学习常见类别，而忽视少数但重要的异常类型。因此，在模型开发和应用中，需要重视数据增强、外部验证、类别平衡、结果解释和医生复核。病灶识别的合理定位，是帮助医生更快发现可疑区域，而不是替代医生完成全部医学判断。

\subsubsection*{\textbf{2. 辅助诊断}}
当影像识别模型在胸部CT中标出一处肺部阴影后，医生接下来需要判断的问题往往是：这处阴影更可能是什么，风险高不高，是否需要进一步检查。类似的问题也会出现在眼底筛查、皮肤病变识别、病理图像分析和心电监测中。单纯发现异常并不足以支持临床判断，医生还需要进一步分析异常对象的性质、类型、严重程度及其与患者整体状态之间的关系。辅助诊断正是在病灶识别和医学信息提取基础上，进一步帮助医生完成疾病判断和状态分析的人工智能任务。

辅助诊断是指利用医学数据和人工智能模型，对疾病类别、病变性质、疾病分型、严重程度或患者状态进行辅助判断的过程。与病灶识别相比，辅助诊断不只回答“有没有异常、异常在哪里”，还进一步回答“异常可能是什么、属于哪一类、严重到什么程度”。例如，在肺结节分析中，辅助诊断可以提示结节良恶性风险；在糖尿病视网膜病变筛查中，系统可以给出病变等级；在病理图像分析中，模型可以辅助判断肿瘤分级；在心电图分析中，系统可以提示是否存在心律失常类型。它的作用是为医生提供更有组织的参考信息，而不是替代医生作出最终诊断。

辅助诊断通常需要综合多种数据。医学影像可以显示病灶形态、位置和范围，检验指标可以反映炎症、代谢、凝血或器官功能状态，病历文本记录患者症状、既往史和治疗过程，生理信号则反映心率、血压、血氧和脑电等动态变化。对于同一名患者，单一数据往往只能提供局部线索。例如，胸部CT可以发现肺部阴影，但要判断其性质，还需要结合症状、感染指标、既往影像、吸烟史和随访变化。辅助诊断模型的价值，正是在于把这些不同来源的信息转化为可用于判断的特征，并形成疾病类别、风险等级或状态评分等结果。

辅助诊断方法大体可以分为传统机器学习、深度学习和多模态融合三类。传统机器学习方法常用于结构化临床数据，例如年龄、性别、血压、血糖、血脂、检验指标和病史变量等。逻辑回归（LR）、决策树（decision tree, DT）、随机森林（RF）、支持向量机（SVM）和梯度提升树（gradient boosting decision tree, GBDT）等模型，可以根据这些变量完成疾病分类、风险分层或状态判断。这类方法的优点是输入变量含义比较明确，结果相对容易解释；不足是对复杂图像、长文本和非线性关系的表达能力有限。

深度学习方法更常用于医学影像、病理图像、心电信号和病历文本等复杂数据。卷积神经网络（CNN）可以从CT、MRI、眼底图像和皮肤镜图像中自动学习图像特征，用于疾病分类和病变分级。循环神经网络（RNN）及其改进结构可以处理心电、脑电和连续监测信号中的时间变化，用于识别异常节律或状态变化。自然语言处理（NLP）可以从病历文本、检查报告和出院小结中提取症状、诊断、药物和治疗信息。深度学习的优势在于能够处理复杂数据，但也更依赖样本量、标注质量和模型解释方法。

多模态融合是辅助诊断中越来越常见的技术路线。多模态融合是指将医学影像、病历文本、检验指标、生理信号或组学数据等不同形式的信息放入同一分析框架中，使模型能够从多个角度理解患者状态。例如，肿瘤辅助诊断可以联合影像分期、病理类型、基因突变和检验结果；心血管疾病辅助判断可以联合胸痛描述、心电图、肌钙蛋白、血压和既往病史；慢病管理中也可以联合院内病历和院外可穿戴设备数据。多模态融合能够提高信息完整性，但也会带来数据缺失、时间不一致和结果解释困难等问题。

辅助诊断的一般过程包括数据准备、特征表示、模型学习、类别判定和结果输出。数据准备阶段需要完成采集、清洗、标注和预处理，保证输入数据尽量准确、完整和可用。特征表示阶段将图像、文本、信号或结构化指标转化为模型可以处理的特征。模型学习阶段利用已有病例建立输入特征与诊断结果之间的关系，并通过验证数据调整模型性能。类别判定阶段根据模型输出生成疾病类别、分型标签、严重程度等级或概率结果。结果输出阶段则把模型判断转化为医生能够理解的形式，例如风险评分、分级结果、可疑依据、热力图或结构化报告。

在实际使用中，辅助诊断结果必须放回临床语境中解释。模型给出的“高风险”\,“疑似恶性”或“中度病变”通常是基于已有数据和训练样本形成的判断，并不等同于最终诊断。若输入数据质量较差、患者情况复杂、训练样本代表性不足，模型可能出现误判。部分疾病还需要病理检查、动态随访或多学科讨论才能明确。因此，辅助诊断的合理定位是帮助医生整理线索、提示风险和提高判断效率，而不是让算法独立决定患者诊断。医学人工智能越接近临床决策，越需要医生复核、结果解释和质量控制。

\subsubsection*{\textbf{3. 疾病风险预测}}
一名慢性心衰患者出院后，医生通常不会只关注本次住院症状是否缓解，还需要判断患者在未来一段时间内是否存在再次住院、心功能恶化或并发症加重的风险。类似情况也出现在糖尿病并发症管理、脑卒中复发评估、肿瘤复发监测和重症患者病情恶化预警中。这类任务关注患者状态在时间上的变化，通过分析当前资料、既往记录和连续监测数据，估计未来发生某类临床事件的可能性。

疾病风险预测是依据患者当前状态及历史信息，对未来疾病进展、并发症发生、病情恶化、治疗反应或不良结局进行评估的任务。与病灶识别和辅助诊断主要关注当前状态不同，它更强调时间维度和趋势信息，需要从多时点数据、连续监测数据或历史病历中识别影响未来结局的模式，并输出风险水平、发生概率或预警结果。对临床工作而言，这类结果可以帮助医生提前识别高风险患者，并为随访、检查和干预安排提供参考。

这类预测任务所依赖的数据通常具有时间关联。电子病历可以记录患者既往病史、住院情况、治疗经过和用药变化；检验指标可以反映炎症、代谢、凝血和器官功能状态；医学影像可以显示病灶范围和结构变化；生理信号和可穿戴设备数据则能够连续记录心率、血压、血氧、活动量和睡眠情况。一次检查只能反映某一时点的状态，连续记录更能显示疾病变化趋势。例如，单次血糖升高可能与饮食、运动或短期应激有关，而连续血糖监测长期显示餐后高峰明显、夜间低血糖频繁，则提示需要重新评估治疗方案。

开展风险预测前，需要先明确预测目标。预测目标是模型需要判断的具体临床事件或结局，例如患者30天内是否再入院、未来1年是否发生脑卒中复发、重症患者未来24小时是否可能病情恶化、肿瘤患者治疗后是否存在较高复发风险。预测目标不同，所需数据、观察时间窗和输出形式也不同。时间窗是指模型观察患者数据和预测未来事件之间设定的时间范围。若时间窗设定不清，模型可能把治疗后的指标变化误当作治疗前风险因素，导致结果失去临床解释基础。

在方法选择上，风险预测既可以使用传统机器学习方法，也可以使用时序深度学习方法。结构化临床数据常用逻辑回归（LR）、支持向量机（SVM）、随机森林（RF）和梯度提升树（GBDT）等方法，适合处理检验指标、人口学变量、病史记录和生活方式信息，完成风险分层和概率估计。对于连续监测数据和随访数据，则更常采用循环神经网络（RNN）、长短期记忆网络（long short-term memory, LSTM）和深度神经网络等方法，以描述变量随时间变化的动态特征。部分任务还会结合静态变量与动态变量，构建多模态预测模型。

完整的建模过程通常包括预测目标设定、样本构建、特征筛选、模型训练、结果校准与风险输出。样本构建阶段需要确定观察指标、结局变量和时间窗，并完成数据清洗与对齐。特征筛选用于保留与风险事件相关且具有医学解释价值的变量，减少无关变量和噪声干扰。模型训练完成后，还需要通过验证和校准评价模型输出是否稳定可信。结果校准是指检查模型给出的概率与真实事件发生率是否接近，若模型预测的高风险人群实际事件发生率并不高，临床使用价值就会受到影响。

预测结果通常以风险等级、概率值、风险评分、趋势曲线或预警信号的形式呈现。例如，心衰患者可被标记为低风险、中风险或高风险；重症监护系统可提示未来24小时内病情恶化风险升高；肿瘤随访模型可给出复发风险评分和重点随访时间。较好的系统还应说明主要影响因素，如肾功能下降、炎症指标升高、近期血压波动、既往多次住院或用药依从性较差等，使医生能够理解模型提示的依据。

这类模型能够帮助临床工作从被动处理转向提前识别，但不能确定单个患者的未来结局。模型输出的是基于已有数据得到的概率估计，患者依从性、治疗调整、突发事件和医疗环境变化都会影响真实结果。训练数据如果主要来自某一类医院、某一地区或某一类患者，模型在其他人群中的表现也可能下降。因此，风险预测应作为临床观察和管理决策的辅助工具，医生仍需结合患者当前表现、检查结果、治疗反应和个人意愿进行综合判断。

\subsubsection*{\textbf{4. 治疗决策支持}}
临床决策常常不是一道单选题，而是在多种方案之间权衡。以一名合并糖尿病和慢性肾功能不全的高血压患者为例，医生在选择降压药时，不能只看血压数值，还要考虑肾功能、血糖控制、既往用药反应、药物禁忌证、并发症风险和患者依从性。对于肿瘤、感染、心血管疾病和慢性病管理等场景，治疗方案更需要在疗效、安全性、患者状态和后续随访之间反复权衡。治疗决策支持就是在这类复杂诊疗过程中，为医生整理信息、比较方案和提示风险的人工智能任务。

治疗决策支持是指在诊断信息、风险评估结果和患者个体特征基础上，为治疗方案选择、诊疗路径调整和干预策略制定提供辅助意见的任务。它并不替代临床医生作出最终决定，而是通过整合患者数据、医学知识和既往证据，形成结构化、可参考的决策信息，帮助医生在复杂资料中更快找到关键问题。常见输出形式包括方案推荐等级、候选方案排序、用药风险提示、剂量调整建议、随访提醒和诊疗路径提示等。

治疗决策支持首先需要准确描述患者状态。患者状态表示是指将与治疗相关的临床信息整理成模型或系统可以分析的表达形式。它通常包括年龄、性别、主要诊断、合并疾病、症状体征、检验指标、影像结果、既往治疗反应、药物过敏史、肝肾功能、用药依从性和患者偏好等内容。例如，一名感染患者的治疗决策需要结合感染部位、病原学检查、药敏结果、肝肾功能和既往抗菌药物使用情况；一名肿瘤患者的治疗方案则可能与病理类型、影像分期、基因突变、体能状态和既往治疗反应密切相关。患者状态整理得越清楚，后续方案比较才越有基础。

候选方案构建是治疗决策支持中的重要环节。候选方案可以来自临床指南、专家共识、医院诊疗路径、药品说明书、规则库、知识库或历史病例。对于慢性病患者，候选方案可能包括不同药物组合、剂量调整、生活方式干预和随访频率；对于肿瘤患者，候选方案可能包括手术、放疗、化疗、靶向治疗、免疫治疗或联合治疗；对于感染患者，候选方案则可能涉及抗菌药物种类、给药剂量、疗程和监测指标。系统的作用不是直接指定唯一方案，而是帮助医生把可选方案和需要警惕的问题整理出来。

治疗决策支持的方法可分为知识驱动和数据驱动两类。知识驱动方法主要利用规则库、知识图谱、贝叶斯推理和专家系统完成辅助判断。规则库适合处理明确、稳定的医学规则，例如药物过敏禁忌、肾功能下降时的剂量调整、危急值处理和检查流程提示。知识图谱（knowledge graph, KG）可以把疾病、症状、检查、药物、治疗方案、不良反应和禁忌证组织成关联网络，用于检查推荐、用药提醒和诊疗路径匹配。知识驱动方法的优点是逻辑相对清楚，医生较容易理解其依据；不足是需要持续更新知识内容，否则可能落后于新的指南和临床证据。

数据驱动方法则从真实病例数据中学习患者特征、治疗方案和临床结局之间的关系。随机森林（RF）、梯度提升树（GBDT）和深度神经网络（deep neural network, DNN）等模型可以用于预测不同方案下的治疗反应、并发症风险或复发概率。对于状态变化明显的连续决策问题，还可以引入强化学习（reinforcement learning, RL）进行建模。强化学习关注在连续过程中如何根据患者状态变化选择行动，并根据结果反馈优化策略。例如，重症监护中的液体管理、血糖控制和部分动态给药问题，都具有连续决策特征。但医疗场景中的强化学习必须经过严格验证，不能将模型探索过程直接用于未经充分评估的真实患者干预。

治疗决策支持的一般步骤包括患者状态表示、候选方案构建、方案评价和结果输出。患者状态表示阶段需要整合病历信息、检验指标、影像结果、既往治疗反应和相关背景资料；候选方案构建阶段根据临床规则、知识库、指南路径或历史病例形成可选方案；方案评价阶段通过规则匹配、模型推断或效果预测，对不同方案的疗效、风险和适用条件进行比较；结果输出阶段通常形成推荐等级、方案排序、风险提示、用药警示或随访建议，供医生进一步判断。

在临床应用中，治疗决策支持常见于用药管理、感染诊疗、肿瘤治疗和慢病干预等场景。以抗菌药物使用为例，系统可以结合感染部位、病原学检查、药敏结果、肝肾功能、过敏史和既往用药记录，提示抗菌药物选择、剂量调整和潜在用药风险。以肿瘤治疗为例，系统可以结合病理类型、影像分期、基因突变和既往治疗反应，辅助医生比较不同治疗方案的适用性。以糖尿病和高血压管理为例，系统可以根据血糖、血压、肾功能、并发症风险和随访记录，提示是否需要调整用药或加强生活方式干预。

治疗决策支持还需要考虑患者个体差异和临床现实条件。临床指南通常给出一般推荐，但真实患者可能存在多病共存、禁忌证、经济负担、药物可及性、依从性不足或个人偏好等问题。一个方案在模型中显示风险较低，并不代表它一定适合当前患者；一个方案在指南中被推荐，也可能因为患者特殊情况需要调整。因此，治疗决策支持系统应提供理由充分、边界清楚的辅助信息，而不是给出看似确定的指令。

这类系统的局限也必须明确。若患者数据不完整、知识库更新不及时、训练样本代表性不足或模型缺乏解释，系统建议可能产生偏差。过多低价值提醒还可能造成医生提醒疲劳，使真正重要的风险提示被忽略。治疗决策本身还涉及医学伦理、患者意愿和医患沟通，这些内容不能完全交给模型处理。因此，治疗决策支持的合理定位，是帮助医生整合资料、比较方案和识别风险，而不是替代医生、患者和临床团队共同完成治疗选择。

\subsubsection*{\textbf{5. 小结}}
医疗人工智能的典型任务主要包括病灶识别、辅助诊断、疾病风险预测和治疗决策支持。病灶识别侧重发现异常对象，辅助诊断侧重疾病性质和类别判断，风险预测侧重未来状态估计，治疗决策支持面向干预方案的辅助分析。不同任务处理的数据形式和目标不同，但都依赖机器学习与深度学习方法对数据特征进行有效建模。

\subsection{医学数据安全与伦理规范}

在医院信息系统中，一份病历不仅记录了患者的疾病诊断，还可能包含姓名、身份证号、联系方式、检查结果、用药记录、手术情况和随访信息。若这些数据在共享、研究或模型训练过程中被不当使用，患者隐私可能被泄露，医疗机构也可能面临管理和法律风险。医学人工智能依赖大量真实数据，但数据越接近真实诊疗过程，越需要严格保护患者权益。

医学数据安全是指在医学数据采集、存储、传输、使用和共享过程中，通过技术和管理措施保护数据不被非法访问、篡改、泄露或滥用。医学数据直接关联个人身份和健康状况，敏感程度高于一般业务数据。电子病历、影像报告、基因检测结果和院外监测记录一旦泄露，可能影响患者就业、保险、社会关系和个人生活。因此，医学数据不能只被看作模型训练材料，更应被看作需要严格管理的患者信息资源。

\subsubsection*{\textbf{1. 隐私保护}}
隐私保护是医学数据使用中的核心要求。隐私保护并不是简单删除患者姓名，而是要尽量降低数据被重新识别到具体个人的风险。数据脱敏（data de-identification）是常见处理方式，通常通过删除、替换或模糊化姓名、身份证号、电话号码、住址、住院号等可识别信息，使数据更适合用于科研、教学或模型训练。对于高度敏感的数据，如基因组数据和罕见病资料，即使去除姓名，也可能因信息特征过于特殊而存在重新识别风险，因此需要更加谨慎地控制使用范围。

\subsubsection*{\textbf{2. 授权管理}}
医学数据的使用应遵循最小必要原则。最小必要原则是指只在完成特定医疗、科研或管理任务所需的范围内访问和使用数据。不同岗位人员对数据的访问权限应有所区别，临床医生、科研人员、系统管理员和外部合作机构不应拥有完全相同的数据访问范围。对于人工智能模型开发而言，研究者应明确数据来源、使用目的、使用范围和保存方式，避免将数据随意复制、下载或转交给无关人员。

\subsubsection*{\textbf{3. 伦理审查}}
伦理审查是医学数据用于科研和人工智能开发前的重要环节。伦理审查通常由医学伦理委员会对研究目的、数据来源、患者权益保护、风险控制和知情同意情况进行评估。知情同意是指患者在了解数据使用目的、可能风险和保护措施后，自愿同意其数据被用于特定场景。对于已经形成的历史数据，若难以逐一重新取得知情同意，也需要根据相关规范进行伦理评估和数据保护处理，不能因为技术上可以使用，就默认伦理上可以使用。

\subsubsection*{\textbf{4. 算法公平}}
医学人工智能不仅要关注数据能不能用，还要关注模型结果是否公平可靠。算法公平性（algorithmic fairness）是指模型在不同性别、年龄、地区、疾病类型和人群来源中应尽量避免系统性偏差。如果训练数据主要来自某一类医院或某一类患者，模型在其他人群中的表现可能下降。例如，一个主要基于大型三甲医院数据训练的模型，未必能直接适用于基层医疗机构患者。医学人工智能应用前，应关注数据代表性和模型泛化能力，避免模型在特定人群中产生不合理判断。

\subsubsection*{\textbf{5. 小结}}
本节介绍了医学数据安全与伦理规范的基本内容。医学数据包含患者身份、健康状况和诊疗过程等敏感信息，在人工智能应用中必须重视隐私保护、授权管理、伦理审查和算法公平。数据脱敏、访问控制、知情同意和合规审查能够降低数据使用风险，但并不能替代医学责任本身。医学人工智能只有在尊重患者权益、保障数据安全和接受临床复核的前提下，才能更稳妥地服务于疾病识别、风险预测和健康管理。

\section{医学影像识别与辅助诊断}

影像科医生的一天，常常从成百上千张图像开始。X线、CT、MRI、超声和核医学影像等检查手段，能够从不同角度反映人体组织结构、器官形态及部分功能状态，是疾病筛查、病灶发现、病情评估和疗效观察的重要依据。随着影像设备普及和检查量增加，单纯依赖人工阅片在效率和一致性方面面临压力。人工智能通过图像预处理、特征提取、异常识别和定量分析，为医学影像识别、处理与辅助诊断提供了新的路径。图9.5展示了医学影像从图像采集、预处理、特征提取、模型识别到辅助诊断结果输出的基本过程。该流程说明，医学影像人工智能并不是直接给出诊断结论，而是通过多个处理环节逐步提取图像信息，并为医生提供可复核的辅助判断依据。

\subsection{医学影像类型与成像特点}

不同医学影像更像是用不同“镜头”观察人体。X线适合快速查看骨骼和胸部轮廓，CT能把人体结构一层层展开，MRI擅长显示软组织，超声可以实时观察器官运动，核医学影像关注代谢和功能，数字病理图像则进入细胞和组织的微观层面。不同成像技术在原理、图像特征、观察重点和临床用途上存在差异，相应的处理方法和识别任务也不相同。如图9.6所示，X线影像、CT、MRI、超声影像、核医学影像和数字病理图像分别从结构、功能、动态和微观层面提供医学信息。

\subsubsection*{\textbf{1. X线影像}}
X线影像可以理解为人体组织在X射线下形成的投影图像。X射线穿透人体后被探测器接收，不同组织对射线的吸收程度不同，骨骼等高密度组织吸收较多，在图像上表现为较高密度影；肺组织等含气结构吸收较少，表现为较低密度影。临床常见X线影像包括胸部X线片、骨关节X线片、腹部平片和乳腺X线摄影等，其中胸部X线片常用于肺部和心胸结构初步观察，骨关节X线片常用于骨折和关节退变判断，乳腺X线摄影则常用于乳腺疾病筛查。

X线影像的优势在于检查速度快、操作相对简便、设备普及率高和检查成本较低，是临床基础影像检查中应用较广的一类方法。在急诊、体检和基层医疗场景中，X线检查能较快提供初步影像信息，为后续是否需要CT、MRI或其他检查提供参考。它能够较直观地显示骨性结构、胸部轮廓和部分高密度异常改变，适合作为初步筛查和常规复查手段。

X线影像也有天然局限。由于它属于二维投影成像，人体内不同组织和结构会叠加到同一平面上，深部病变、低对比度病灶和边界不清的异常区域可能被正常结构遮挡。部分早期病变在X线影像中表现并不典型，影像判读需要结合解剖结构、密度变化、病灶形态和临床资料综合判断。图像质量还会受到体位、曝光条件、呼吸运动和设备参数等因素影响。

\subsubsection*{\textbf{2. CT}}
CT可以把人体内部结构按层面展开观察，它利用X射线围绕人体进行断层扫描，再通过计算机重建形成横断面图像。与普通X线影像的二维投影不同，CT能够获得人体不同层面的断面信息，减少组织重叠对判读的影响。CT图像通常以连续切片形式呈现，也可通过后处理形成冠状位、矢状位及三维重建图像，从而更清楚地显示器官、组织和病变之间的空间关系。临床常见CT检查包括颅脑CT、胸部CT、腹部CT、骨关节CT以及增强CT等。

CT的临床价值主要体现在速度快、空间分辨率高和结构显示清晰。颅脑CT常用于出血、外伤和占位性病变的初步判断，胸部CT能较清楚地显示肺实质、气道、胸膜及纵隔结构，腹部CT可观察肝、胆、胰、脾、肾等器官形态及局部病变，骨关节CT有助于显示复杂骨折、骨质破坏和关节结构改变。薄层CT和三维重建技术使细小病灶、复杂解剖结构和空间毗邻关系能够得到更清楚的呈现。

CT图像以密度信息明确、组织结构层次清楚为特点。空气、脂肪、软组织、骨骼和钙化等结构在CT图像中密度不同，为病灶发现和结构判断提供了基础。需要注意的是，CT检查使用电离辐射，部分人群需要严格把握适应证；增强CT还涉及对比剂使用，应关注过敏反应和肾功能情况。部分软组织病变在CT中的对比度不如MRI清楚，早期或微小病变也可能受到层厚、重建参数和图像噪声影响。

\subsubsection*{\textbf{3. MRI}}
MRI像是用磁场和射频脉冲读取人体组织的信号。人体组织中的氢质子在强磁场和射频脉冲作用下产生磁共振信号，经计算机重建后形成图像。不同组织的水分含量、质子密度和弛豫特性存在差异，因此在MRI图像中呈现不同信号强度。与X线和CT依赖电离辐射不同，MRI不使用电离辐射，能够从多个方位显示组织结构和病变范围。常见MRI检查包括颅脑MRI、脊柱MRI、关节MRI、腹部MRI、盆腔MRI和乳腺MRI等。

MRI的突出特点是软组织分辨能力较强，能够较清楚地显示肌肉、脂肪、神经、血管、韧带、软骨和实质器官等组织之间的差异。在神经系统、肌骨系统、脊柱、关节和部分肿瘤性疾病检查中，MRI能够提供较丰富的结构信息。MRI还具有多方位成像能力，可以根据需要获得横断面、冠状面和矢状面图像，有利于观察病变与周围组织之间的空间关系。对于部分病变，增强MRI还可以通过对比剂显示血供、强化方式和病灶边界，从而辅助判断病变性质和范围。

MRI的另一重要特点是成像序列丰富。常见序列包括T1加权成像、T2加权成像、弥散加权成像、液体衰减反转恢复序列、磁敏感加权成像以及动态增强序列等。不同序列反映的组织信息并不相同，T1加权成像更适合观察解剖结构，T2加权成像对液体和水肿较敏感，弥散加权成像可用于反映水分子扩散受限情况，液体衰减反转恢复序列有助于显示脑白质病变和脑组织异常信号。临床判读MRI时，通常需要将多个序列放在一起比较，综合分析病灶信号特点、位置关系、边界形态和强化表现。

MRI也存在一定局限。其检查时间通常长于X线和CT，对患者配合度要求较高，运动伪影、呼吸伪影和金属伪影可能影响图像质量。部分体内金属植入物、心脏起搏器或其他特殊装置患者需要严格评估检查适应证。MRI对钙化和骨皮质显示不如CT直观，急诊快速评估场景中也常受到检查时间和设备条件限制。MRI图像判读需要结合序列特征、解剖结构和临床资料进行综合判断，单一序列往往难以完整反映病变性质。

在人工智能处理中，MRI图像分析通常涉及图像配准、多序列融合、组织分割、病灶识别、特征提取和分级判断等内容。由于MRI常包含多序列数据，模型需要处理不同序列之间的空间对应关系，并整合各序列所提供的互补信息。对于颅脑、脊柱、关节和肿瘤相关MRI任务，人工智能模型常关注组织边界、异常信号、病灶范围、强化模式和多时点变化。相关方法可采用二维或三维卷积神经网络、多模态融合网络、注意力机制和Transformer结构等，用于提取组织结构和病变信号特征。

\subsubsection*{\textbf{4. 超声影像}}
超声影像更像是用声音观察身体。超声探头向体内发射高频声波，声波在不同组织界面发生反射后被探头接收，再经过信号处理形成二维图像、动态视频或血流图像。常见超声检查包括腹部超声、心脏超声、甲状腺超声、乳腺超声、妇产科超声和血管超声等。二维超声主要观察器官形态和组织结构，彩色多普勒超声可显示血流方向和速度变化，超声弹性成像则可评估组织硬度和弹性特征。

超声影像具有实时、无创、便捷、可重复检查和可床旁操作等特点，在临床检查中应用范围较广。与CT和MRI相比，超声设备移动性更强，检查过程更加灵活，适用于动态观察器官运动、血流变化和局部结构变化。心脏超声能够观察心腔结构、瓣膜活动和心功能状态，腹部超声可用于观察肝、胆、胰、脾、肾等器官形态，妇产科超声常用于胎儿发育和子宫附件情况评估，血管超声则可用于观察血管狭窄、血栓和血流动力学变化。

超声影像也存在较明显的局限。图像质量容易受到操作者经验、探头角度、检查部位、患者体型、气体干扰和声窗条件等因素影响。与CT和MRI相比，超声图像的空间分辨率和组织对比度相对有限，部分深部结构或被骨骼、气体遮挡的区域显示不够清楚。超声图像中的边界、纹理和回声强度变化需要结合解剖位置、动态表现和临床资料进行综合判断。对于同一部位，不同操作者获得的图像切面和显示效果也可能存在差异，这使超声数据的标准化和一致性处理更为重要。

\subsubsection*{\textbf{5. 核医学影像}}
核医学影像关注的是组织和器官“工作得怎么样”。放射性核素示踪剂进入人体后，会随血流分布到特定组织、器官或病变区域，并释放可被探测设备接收的射线信号。设备根据这些信号重建图像，从而显示组织代谢、血流灌注、受体表达或器官功能状态。常见核医学影像包括PET和SPECT。与主要显示解剖结构的X线、CT和MRI相比，核医学影像更侧重反映功能变化和代谢活动。

PET通常通过放射性示踪剂显示组织代谢活性，在肿瘤评估、神经系统疾病和心血管疾病检查中应用较多。SPECT则通过探测单光子发射信号反映器官血流、功能分布和代谢状态，可用于心肌灌注、脑血流和骨显像等检查。核医学影像的特点是功能信息较为突出，能够在部分结构改变尚不明显时提供代谢或功能层面的线索。不过，这类影像的空间分辨率通常低于CT和MRI，图像细节不如结构影像清晰，单独判读时需要结合解剖信息进行综合分析。

在临床工作中，核医学影像常与CT或MRI联合使用，形成PET-CT、SPECT-CT或PET-MRI等多模态影像。结构影像能够提供清晰的解剖定位，核医学影像能够提供代谢和功能信息，两类信息结合后，可以更准确地判断异常信号所在部位及其医学意义。在人工智能处理中，核医学影像分析通常涉及图像配准、代谢区域识别、功能参数提取和多模态信息融合等内容。模型既需要识别局部异常摄取区域，也需要结合结构影像判断其解剖位置和空间关系。

\subsubsection*{\textbf{6. 数字病理图像}}
数字病理图像把医学影像推进到细胞和组织层面。组织切片经过染色、扫描和数字化采集后，可形成高分辨率图像资料。传统病理诊断主要依赖显微镜下观察组织和细胞形态，数字病理则通过切片扫描设备将玻璃切片转化为可存储、可放大、可计算的图像数据。常见数字病理图像包括常规苏木精-伊红染色图像、免疫组织化学染色图像和特殊染色图像等。

与X线、CT和MRI等放射影像相比，数字病理图像更接近组织和细胞层面的微观信息。其图像分辨率高，细胞核形态、细胞排列、组织结构和染色深浅等细节较为丰富，在肿瘤诊断、病理分型、分级判断和组织学评估中具有重要作用。数字病理图像通常数据量较大，一张全切片图像可能包含大量局部区域和细胞结构，判读时需要在低倍视野下观察组织整体结构，也需要在高倍视野下分析细胞形态和局部病变特征。

数字病理图像的复杂性主要体现在图像尺度大、局部细节密集和病变差异细微等方面。不同染色批次、扫描设备、切片质量和组织处理过程，都会影响图像颜色、清晰度和背景噪声。正常组织、炎症区域和肿瘤组织之间有时存在形态相似性，病变边界也可能不够清楚。病理判读对专业经验依赖较强，通常需要结合组织结构、细胞异型性、核分裂象、染色表达和临床资料进行综合判断。

在人工智能处理中，数字病理图像分析通常涉及图像切块、颜色标准化、细胞检测、组织区域识别、病变区域定位和分类分型等内容。由于全切片图像尺寸较大，模型通常难以一次性处理整张图像，常采用局部切块方式提取图像区域，再对不同区域的特征进行汇总分析。对于细胞层面的任务，模型需要识别细胞核、细胞边界和局部组织结构；对于组织层面的任务，模型需要判断不同区域的组织类型、病变程度和空间分布。数字病理图像为人工智能提供了从宏观影像分析进入微观组织分析的重要数据基础。

\subsection{图像处理流程与识别方法}

一张原始医学影像不能直接“扔给”模型就期待得到可靠结论。它可能带有噪声、伪影、灰度差异、层厚差异和设备参数差异。医学影像进入人工智能分析前，通常需要经过图像预处理、目标定位、特征提取、模型识别和结果评价等环节。图像处理流程的作用，是将原始影像转化为质量较稳定、结构较清晰、信息较完整的输入数据，并在此基础上完成病灶识别、图像分割、类别判断和辅助分析等任务。如图9.7所示，医学影像进入模型分析前需要经过图像预处理、区域提取与图像分割、特征表示、模型训练和结果评价等步骤。

\subsubsection*{\textbf{1. 图像预处理}}

在胸部CT筛查肺结节时，医生看到的是一组已经成像完成的断层图像，但这些图像并不一定适合人工智能模型直接分析。不同医院使用的扫描设备不同，层厚、重建算法、窗宽窗位和图像分辨率也可能存在差异。同一名患者在不同时间复查时，体位、呼吸配合和扫描范围也可能不完全一致。对于医生来说，这些差异可以通过阅片经验进行判断；对于模型来说，如果不先进行必要处理，它可能把设备差异、噪声或显示条件误认为病灶特征。

图像预处理是医学影像进入模型分析前的准备环节，主要目的是改善图像质量，统一数据表达形式，并减少非目标因素对后续识别结果的干扰。它不直接完成疾病诊断，而是为后续的病灶检测、图像分割、特征提取和辅助诊断提供更稳定的输入。常见的预处理内容包括图像去噪、灰度归一化、对比度增强、尺寸调整、重采样、图像配准和感兴趣区域提取等。

图像去噪主要用于减弱随机噪声和采集干扰。医学影像在采集过程中可能受到设备性能、扫描剂量、患者运动和重建算法影响，图像中会出现颗粒感、模糊或局部伪影。去噪可以采用滤波、平滑处理或基于深度学习的方法，使目标结构更加清楚。例如，低剂量CT虽然可以减少辐射暴露，但图像噪声相对更明显，适当去噪有助于模型识别小结节和低对比病灶。需要注意的是，去噪不能过度，否则可能把细小病灶边缘或组织纹理一并抹掉，反而降低模型识别能力。

灰度归一化用于减少不同设备和扫描条件造成的灰度分布差异。归一化是指按照一定规则调整图像灰度或像素值范围，使不同图像在数值尺度上更接近。对于CT图像，像素值通常与组织密度有关，不同窗宽窗位会影响肺组织、骨骼和软组织的显示效果；对于MRI图像，不同序列和设备参数也会造成信号强度差异。通过归一化处理，模型可以更专注于病灶形态和组织结构，而不是被图像整体亮度或灰度范围影响。

图像增强用于突出目标结构与周围背景之间的差异。增强处理可以改善边缘、纹理、局部密度变化或低对比区域的可见性。例如，在眼底图像中，增强处理可以使血管走行、出血点和渗出区域更加清楚；在病理图像中，颜色校正和染色归一化有助于减弱不同切片染色深浅带来的差异；在超声图像中，增强处理可以帮助突出组织边界。增强的目标不是让图像“看起来更漂亮”，而是让与医学任务相关的结构更容易被模型捕捉。

尺寸调整和重采样主要用于统一图像空间尺度。不同影像数据可能具有不同分辨率、像素间距、层厚和体素大小。对于CT、MRI等三维影像，若不同病例的切片厚度或体素大小差异较大，模型在学习空间结构时就会受到影响。重采样可以把图像调整到相对统一的空间分辨率，使病灶大小、器官形态和空间关系具有更好的可比性。例如，肺结节检测模型通常需要在较统一的体素尺度下分析结节大小和空间位置；心脏MRI分析也需要保证不同帧或不同序列之间的空间对应关系尽量稳定。

图像配准用于将不同时间点、不同序列或不同模态的影像对齐。配准是指通过空间变换，使两幅或多幅图像中的同一解剖结构尽量重合。在治疗前后影像比较中，配准可以帮助医生和模型判断病灶是否缩小、增大或发生位置变化；在MRI多序列分析中，配准可以使T1、T2、增强序列等图像在同一空间中进行联合分析；在PET-CT融合分析中，配准可以把代谢信息和解剖结构对应起来。图像配准对多模态影像分析和随访评估都很关键，但如果配准不准确，也可能造成结构错位和错误判断。

感兴趣区域提取也是常见的预处理方式。感兴趣区域是指与当前任务关系较大的图像区域，例如肺结节检测中的肺野区域、肝肿瘤分析中的肝脏区域、心脏功能评估中的心腔区域。通过先去除无关背景，模型可以减少对无关组织、设备标记和图像边缘信息的关注。例如，肺野分割可以排除胸壁和纵隔区域，使结节检测模型集中分析肺组织内部结构；眼底图像分析可以先定位视盘和黄斑区域，为后续病变识别提供空间参考。

图像预处理并不是固定不变的步骤组合，而应根据影像类型和具体任务选择。CT图像常关注窗宽窗位、体素尺度和空间方向；MRI图像常关注序列差异、信号归一化和配准；超声图像常需要处理斑点噪声和切面差异；病理图像则更重视颜色标准化、切块和组织区域筛选。预处理过少会让模型受到噪声和格式差异干扰，预处理过度则可能改变原始医学信息。因此，预处理参数和流程需要结合临床任务、图像特点和模型要求进行设计，并保留必要的原始图像信息，便于医生复核和结果追溯。

\subsubsection*{\textbf{2. 区域提取与图像分割}}

在肝脏肿瘤影像分析中，医生首先需要确认图像中的肝脏区域，再进一步观察肿瘤位置、大小、边界和与周围血管的关系。如果模型直接在整张腹部CT图像上寻找病灶，就会同时面对脾脏、胃肠道、骨骼、脂肪和其他背景结构，分析难度明显增加。对人工智能而言，先把与任务相关的区域找出来，再对其中的器官或病灶进行精细分析，是医学影像处理中的常见思路。区域提取与图像分割便是围绕这一过程展开的关键步骤。

区域提取是指从原始医学图像中选取与当前诊断或分析任务相关的器官、组织或局部范围。它的作用是缩小模型关注范围，减少无关背景对后续识别的干扰。例如，肺结节检测常先提取肺野区域，肝肿瘤分析常先定位肝脏区域，眼底病变识别可先关注视盘、黄斑或血管区域。经过区域提取后，模型不必在整幅图像中盲目搜索，而可以将计算资源集中在更有医学意义的范围内。

图像分割比区域提取更精细。图像分割（image segmentation）是指将图像中的器官、组织或病灶区域从背景中划分出来，并形成像素级或体素级的边界结果。像素是二维图像中的最小显示单元，体素则是三维医学影像中的最小体积单元。对于一张CT图像，肺野、肝脏、脑组织、肿瘤、出血区域和血管结构都可以成为分割对象。分割结果不仅能说明病灶在哪里，还能进一步支持面积、体积、形态和随访变化分析。

在临床场景中，分割结果常用于定量评估。以脑出血患者为例，医生需要判断出血范围是否扩大，血肿体积是否达到干预标准；以肿瘤疗效评估为例，治疗前后病灶体积变化可以辅助判断治疗反应；以心脏影像分析为例，心腔分割可以用于计算心室容积和射血分数。这些任务都需要比较准确的边界结果。若分割边界偏差较大，后续面积、体积和功能参数也会受到影响。

传统图像分割方法主要依赖图像灰度、边缘和区域一致性。阈值分割是根据像素灰度或信号强度设定阈值，将目标与背景区分开来，适合目标和背景对比较明显的图像。边缘检测用于寻找灰度变化明显的位置，常用于结构边界较清楚的图像。区域生长从一个或多个种子点出发，把灰度或纹理相近的邻近区域逐步合并。活动轮廓模型通过不断调整轮廓位置，使其贴合目标边界。聚类方法则根据像素或体素特征把图像划分为若干类别。这些方法原理相对直观，但容易受到噪声、边界模糊、灰度不均和参数设置影响。

随着深度学习发展，医学图像分割更多采用神经网络模型。全卷积网络（fully convolutional network, FCN）是较早用于像素级预测的深度学习结构，它可以把图像分类网络改造成能够输出区域结果的模型。U-Net是一种常用于医学图像分割的编码器-解码器结构神经网络。编码器负责提取图像中的多层特征，解码器负责逐步恢复空间细节，跳跃连接则把浅层位置信息与深层语义信息结合起来，使模型更好地保留边界细节。由于医学数据标注成本较高，U-Net在样本数量有限的场景中也较为常用。

对于目标边界复杂或目标较小的任务，分割模型还可以结合多尺度特征、注意力机制和实例分割方法。多尺度特征可以让模型同时关注大范围结构和细小病灶，适合肺结节、微小出血点和小肿瘤等任务。注意力机制可以引导模型更加关注与目标相关的区域，减少背景组织干扰。Mask
R-CNN是一种常用于实例分割的模型，它不仅能够检测目标位置，还能为每个目标生成对应的分割掩膜，适合多个病灶或多个细胞目标同时出现的场景。

CT和MRI等三维影像还需要考虑空间连续性。若只对单张切片进行分割，模型可能忽略相邻切片之间的结构关系。三维卷积神经网络（three-dimensional convolutional neural network, 3D CNN）和三维U-Net可以直接处理三维体数据，利用前后切片之间的连续信息进行分割。例如，脑肿瘤分割、肺结节分割、肝脏分割和心脏结构分割都常涉及三维空间信息。三维模型通常能获得更完整的空间表达，但计算资源消耗更大，对数据量和标注质量也有更高要求。

区域提取和图像分割也存在明显边界。首先，医学图像中的目标并不总是边界清晰。炎症影、浸润性肿瘤、早期病灶和低对比结构常与周围组织过渡自然，很难给出绝对精确边界。其次，不同医生对同一病灶边界的判断可能存在差异，训练数据中的标注不一致会影响模型学习。再次，图像质量、扫描参数、伪影和患者运动都会影响分割结果。因此，分割结果应由医生结合原始图像复核，特别是在手术规划、放疗靶区勾画和疗效评估等高风险任务中，不能简单依赖模型自动输出。

\subsubsection*{\textbf{3. 特征提取与特征表示}}

医生观察一张胸部CT图像时，会注意结节的大小、密度、边缘是否毛刺、内部是否均匀，以及它和血管、胸膜之间的关系。观察皮肤镜图像时，医生会关注病灶颜色是否不均、边界是否规则、结构是否对称。人工智能模型不能像医生一样直接用临床经验理解图像，它需要先把图像中的这些视觉线索转化为可以计算的形式。特征提取与特征表示正是完成这一转换的关键步骤。

特征提取是指从医学图像中获得具有识别或判断价值的信息。特征表示是指把这些信息转化为数值、向量、特征图或其他模型可以处理的表达形式。医学影像中的病变常表现为密度、信号强度、纹理、形态、边界和空间分布等变化。模型只有把这些变化转化为可计算的特征，才能进一步完成病灶识别、疾病分类、风险预测和疗效评估等任务。

传统机器学习方法通常依赖人工设计特征。人工设计特征是由研究者根据医学知识和图像特点预先定义的特征类型，再通过算法从图像中计算出来。常见特征包括灰度特征、纹理特征、形状特征、边缘特征和统计特征等。灰度特征反映局部区域的强度分布，例如CT图像中某一区域的密度高低；纹理特征描述组织内部的粗糙程度和空间排列规律，例如病理图像中细胞和腺体排列是否紊乱；形状特征用于表达病灶大小、圆整程度、边界规则性和几何形态；边缘特征则关注目标与周围组织之间的过渡情况。

这些人工特征常用于样本量较小、目标结构较明确的任务。例如，在肺结节分析中，研究者可以提取结节直径、体积、密度、边缘毛刺和形状规则性等特征；在乳腺影像分析中，可以提取钙化点分布、肿块边界和纹理变化；在病理图像中，可以提取细胞核大小、核质比、染色强度和组织排列特征。随后，这些特征可以输入支持向量机、随机森林、逻辑回归或其他分类模型中，用于完成良恶性判断或疾病分型。人工设计特征的优点是医学含义较清楚，便于解释；不足是依赖人工经验，难以完整表达复杂图像中的深层模式。

特征提取后，通常还需要进行特征筛选或降维处理。特征筛选是从大量候选特征中保留与任务更相关的特征，减少冗余信息和噪声干扰。降维是将高维特征压缩为少数综合特征，使模型训练更稳定。主成分分析（PCA）是常见降维方法之一，可将多个相关变量转化为少数综合变量。对于医学影像组学（radiomics）任务，模型可能从图像中提取大量形状、纹理和灰度特征，如果不进行筛选或降维，模型容易受到冗余变量影响，也更容易在小样本数据上过拟合。

深度学习方法则更多依赖自动特征学习。卷积神经网络（CNN）可以直接从图像中逐层学习特征。浅层网络通常提取边缘、纹理、局部对比度等基础视觉信息，中间层逐渐组合出局部结构和形态模式，高层网络则形成与病灶类别或疾病状态相关的抽象表示。可以把CNN理解为模型自己学习“看图重点”的过程，它不需要研究者提前手工定义所有特征，而是在训练样本和标签的引导下逐步形成特征表达。

在医学影像任务中，深度特征常以特征图或向量形式存在。特征图保留了一定空间位置信息，适合用于病灶定位和图像分割；特征向量则常用于分类、风险评分和结果预测。例如，皮肤病变识别模型可以从皮肤镜图像中学习颜色分布、边界形态和局部纹理；眼底病变筛查模型可以学习血管走行、出血点和渗出区域；病理图像模型可以学习细胞核形态、腺体结构和组织排列方式。这些特征并不一定能被人直接看见，但可以通过热力图、注意力图或局部区域分析等方式帮助医生理解模型关注的位置。

对于复杂医学影像任务，仅依赖单一尺度特征往往不够。多尺度特征融合是指同时利用不同大小、不同分辨率或不同层级的图像特征，使模型既能关注整体结构，也能捕捉细小病灶。例如，肺结节检测需要关注几毫米的小结节，也需要理解肺野和血管等背景结构；病理图像分析既要观察单个细胞核，也要分析组织结构和腺体排列；眼底图像中微血管瘤很小，但视盘、黄斑和血管分布又提供重要背景信息。多尺度融合可以帮助模型在局部细节和整体结构之间建立联系。

注意力机制也常用于改进特征表示。注意力机制可以让模型在分析图像时更加关注与任务相关的区域或通道，减少背景噪声和无关结构的影响。例如，在皮肤病变识别中，模型应更多关注病灶本身，而不是图像边缘、尺标或背景皮肤；在病理肿瘤分级中，模型需要从大量组织小块中筛选更关键的肿瘤区域；在心脏影像分析中，模型需要关注心腔边界和室壁运动相关结构。注意力机制并不是让模型真正“理解医学”，但它可以提高关键区域在特征表达中的权重。

预训练模型也常用于医学图像特征学习。预训练是指模型先在较大规模数据上学习通用图像特征，再迁移到具体医学任务中继续训练。由于医学数据标注成本高，很多任务难以获得足够大的标注数据集。通过迁移学习，模型可以利用已有图像特征基础，再适应眼底筛查、皮肤病变识别、胸部影像分类等具体任务。需要注意的是，自然图像和医学图像差异较大，预训练特征不一定总是适合医学场景，仍需要结合医学数据进行验证和调整。

特征表示的质量直接影响后续模型表现。好的特征应尽量包含与疾病相关的稳定信息，例如病灶形态、组织结构、异常纹理和空间分布；同时应尽量减少与任务无关的信息，例如设备差异、扫描参数差异、图像标记、背景噪声和偶然伪影。如果模型学习到的主要是医院来源、设备型号或图像格式，而不是病灶本身，那么它在新医院或新设备上的表现可能明显下降。因此，特征提取与特征表示不仅是技术步骤，也关系到模型能否具有临床可用性和泛化能力。

\subsubsection*{\textbf{4. 识别方法与模型训练}}

在肺结节筛查中，模型需要判断一处可疑阴影是不是结节；在眼底筛查中，模型需要判断图像是否存在视网膜病变；在皮肤镜图像中，模型还可能需要判断病变属于色素痣、脂溢性角化、基底细胞癌还是黑色素瘤。虽然这些任务面对的数据不同，但它们都有一个共同目标：让模型根据图像中的特征，对目标、类别或状态作出判断。识别方法与模型训练，正是医学影像人工智能从“看见图像”走向“形成判断”的关键环节。

图像识别是利用模型对医学影像中的目标、类别或状态进行判断的过程。根据任务目标不同，它可以用于病灶有无判断、疾病类别识别、良恶性判别、器官结构识别和异常程度分析。若模型只判断整张图像是否异常，通常属于图像分类任务；若模型需要指出病灶位置，则更接近目标检测任务；若模型还要划出病灶边界，则需要结合图像分割任务。医学影像识别往往不是单一步骤，而是与预处理、区域提取、特征表示和结果解释共同组成完整分析流程。

传统机器学习方法通常以人工设计特征为输入，再利用分类器完成识别。也就是说，研究者先从图像中提取灰度、纹理、形状、边缘和统计特征，再让模型根据这些特征判断图像类别或病灶性质。逻辑回归（LR）、支持向量机（SVM）、决策树（DT）、随机森林（RF）、K近邻（KNN）和梯度提升树（GBDT）等方法都可用于这类任务。其中，SVM适合处理中小规模数据中的分类问题，RF能够处理多维特征并具有一定抗噪能力，GBDT在结构化特征和表格化特征处理中较为常用。这类方法的优势是过程相对清楚，特征含义较容易解释；局限在于依赖人工特征设计，面对复杂图像时表达能力有限。

深度学习方法在医学影像识别中应用更为广泛。卷积神经网络（CNN）是图像识别的基础模型，它可以从原始图像中自动学习边缘、纹理、形态和空间结构等特征。常见结构包括VGG、残差网络（ResNet）、密集连接网络（DenseNet）和EfficientNet等。VGG结构较规整，便于理解卷积层逐步提取特征的过程；ResNet通过残差连接缓解深层网络训练困难；DenseNet通过特征复用增强信息传递；EfficientNet则在模型规模和识别性能之间进行平衡，常用于需要兼顾性能和计算效率的图像分类任务。对于非计算机专业读者，可以把这些模型理解为不同结构的图像特征学习器，它们的共同作用是从图像中提取与诊断任务相关的信息。

不同医学影像任务对模型结构有不同要求。对于胸部X线、眼底照相和皮肤镜图像等二维图像，二维CNN及其改进结构通常能够完成分类、检测和初步判别。对于CT和MRI等三维影像，单张切片可能无法完整反映病灶形态和空间关系，因此常采用三维卷积神经网络（3D CNN）或三维U-Net等模型处理体数据。对于多序列MRI、PET-CT融合影像或影像联合临床指标的任务，可以采用多分支网络或特征融合网络，将不同来源的信息分别提取特征后再进行整合。这样可以避免把不同模态简单拼接在一起，也能保留各类数据自身特点。

模型训练是让模型从已标注数据中学习判断规律的过程。一般而言，训练前需要先构建训练集、验证集和测试集。训练集用于让模型学习图像特征与标签之间的关系，验证集用于调整模型结构和训练参数，测试集用于评价模型在未见数据上的表现。标签设定也很关键，它决定模型要学习什么任务。例如，标签可以是“正常/异常”，也可以是“良性/恶性”，还可以是具体疾病类别、病变等级或风险分层。如果标签定义不清，模型即使训练过程看似顺利，输出结果也可能难以解释。

训练过程中还需要选择损失函数和优化方法。损失函数是衡量模型预测结果与真实标签之间差距的指标，模型训练的目标就是不断减小这种差距。分类任务常用交叉熵损失，分割任务常结合Dice损失或其他区域重叠指标。优化方法则用于不断调整模型参数，使模型在训练数据上逐渐学会正确判断。对于初学者来说，不必陷入复杂公式，可以把这一过程理解为模型反复看图、判断、对答案、修改内部参数，直到它在训练数据和验证数据上都达到相对稳定的表现。由于模型输出基于训练数据中的统计关系，仍需要通过验证和医生复核确认其可靠性。

医学影像模型训练还常需要处理数据量不足、类别不平衡和过拟合等问题。数据增强是常用方法之一，它通过旋转、翻转、裁剪、亮度调整、噪声扰动等方式生成更多训练样本，使模型对图像变化更加稳健。类别不平衡是指某些类别样本很多，而某些关键类别样本很少，例如正常影像远多于罕见病灶影像。若不处理，模型可能更倾向于预测常见类别。过拟合则是指模型在训练数据上表现很好，但遇到新数据时表现下降。为了减少这些问题，需要采用数据增强、类别权重调整、交叉验证、正则化、早停策略和外部验证等方法。

模型训练完成后，需要通过多种指标评价其效果。分类任务常用准确率、敏感度、特异度、精确率、F1值和受试者工作特征曲线下面积（area under the receiver operating characteristic curve, AUC）等指标。敏感度反映模型发现阳性病例的能力，特异度反映模型排除阴性病例的能力，AUC用于评价模型区分阳性和阴性样本的整体能力。分割任务常用Dice系数和交并比等指标，评价模型分割区域与人工标注区域的重叠程度。不同指标关注重点不同，不能只看一个数值就判断模型好坏。比如一个模型准确率很高，但对少数高风险病灶漏检严重，那在临床上依然不能放心使用。

识别模型的输出形式应服务于医生理解和复核。分类模型可以输出类别标签和概率评分，检测模型可以输出病灶位置框，分割模型可以输出边界轮廓或分割掩膜，部分系统还会提供热力图或注意力图，显示模型重点关注的区域。这些结果可以帮助医生快速定位可疑区域，也能为后续定量分析和辅助诊断提供基础。但模型输出不能直接等同于最终诊断，尤其在图像质量较差、病灶边界模糊、患者情况复杂或模型缺乏外部验证时，更需要医生结合原始影像和临床资料进行判断。

\subsubsection*{\textbf{5. 结果输出与性能评价}}

医生使用医学影像辅助诊断系统时，看到的通常不是模型内部复杂的参数，而是更接近临床工作习惯的结果形式。例如，在肺结节检测中，系统可能在CT图像上标出可疑结节位置，并给出直径和风险评分；在眼底病变筛查中，系统可能提示是否存在糖尿病视网膜病变及其分级；在心脏影像分析中，系统可能输出心腔分割轮廓和射血分数。这些结果只有能够被医生理解、复核和追溯，才有可能真正进入临床分析流程。

模型结果输出是指模型完成分析后，将判断结果以类别标签、概率值、病灶定位框、分割轮廓、热力图或定量参数等形式呈现出来的过程。类别标签表示模型判断的疾病类型或状态，例如“正常”\,“异常”\,“良性”\,“恶性”；概率值反映模型对某一类别判断的置信程度；定位框用于显示可疑病灶所在的大致位置；分割轮廓用于展示器官、组织或病灶的边界；热力图可以提示模型在判断时重点关注的区域；定量参数则用于描述病灶大小、面积、体积、密度或信号变化。

不同任务适合不同的输出形式。分类任务常输出类别标签和概率评分，例如判断皮肤病变属于色素痣还是黑色素瘤；检测任务常输出目标位置框和检出结果，例如在胸部CT中标出肺结节位置；分割任务常输出像素级或体素级区域结果，例如勾画肿瘤边界或心腔轮廓；定量分析任务则输出面积、体积、直径、射血分数等数值结果。这些输出形式应与临床任务相匹配，而不是简单追求图像界面看起来“智能”。若医生无法理解输出含义，模型结果再复杂也很难产生实际价值。

性能评价是判断模型是否可靠的重要环节。评价模型表现不能只用“准不准”一句话概括，因为不同医学任务关注的风险并不相同。分类任务常用准确率、敏感度、特异度、精确率、F1值和受试者工作特征曲线下面积（AUC）等指标。准确率反映总体判断正确的比例；敏感度表示模型发现阳性病例的能力；特异度表示模型排除阴性病例的能力；精确率关注被模型判为阳性的样本中有多少是真阳性；F1值综合考虑精确率和敏感度；AUC则用于评价模型区分阳性和阴性样本的整体能力。

医学任务选择评价指标时，应结合实际使用场景。筛查任务通常更重视敏感度，因为漏掉真正患病者可能造成延误诊治；确诊辅助任务则需要兼顾敏感度和特异度，避免过多误报造成不必要检查；罕见病或高风险疾病识别还需要关注样本不平衡问题。一个模型如果准确率很高，但主要是因为正常样本占多数，同时对少数高危病例检出能力不足，那么它在临床上并不一定可靠。

对于图像分割任务，评价重点通常不在类别判断，而在区域是否划得准确。Dice系数和交并比是常用指标，它们用于衡量模型分割区域与人工标注区域之间的重合程度。Dice系数越高，说明两者重合越好；交并比也用于评价预测区域与真实区域的交集和并集之间的关系。边界距离类指标则关注分割边界与人工标注边界之间的偏差，适合用于肿瘤边界、器官轮廓和放疗靶区等对边界精度要求较高的任务。对于检测任务，常关注检出率、误报率、平均精度和不同病灶大小下的检出效果。

模型性能还需要通过合理的数据划分和验证方式进行评价。训练数据上的表现不能代表模型真实能力，因为模型可能只是记住了训练样本中的特征。独立测试集用于检验模型在未参与训练数据上的表现，外部验证则用于评估模型在不同医院、不同设备、不同人群或不同采集条件下的稳定性。医学影像模型尤其需要关注泛化能力。一个在某家医院CT数据上表现较好的肺结节模型，到了另一家医院可能会受到扫描参数、层厚、重建算法和患者来源差异的影响，性能出现下降。

性能评价还应关注结果稳定性和可解释性。结果稳定性是指模型在相近输入条件下能否给出一致判断。如果轻微改变图像亮度、裁剪范围或扫描条件就导致结果大幅变化，模型就不适合直接用于高风险临床任务。可解释性则关注医生能否理解模型判断的主要依据。热力图、注意力区域、重要特征提示和结构化报告都可以帮助医生查看模型是否关注了合理的医学区域。若模型把图像边缘标记、设备字符或无关背景当作判断依据，即使指标看起来不错，也需要重新评估。

性能评价的目的不是为模型“评个高分”，而是判断它能否安全、稳定、可解释地支持医学任务。评价结果应说明模型适用于哪些数据、哪些人群和哪些场景，也应说明它在哪些情况下可能失效。对于准备进入临床流程的模型，还需要关注误报、漏报、医生采纳情况、工作流程影响和持续监测机制。医学人工智能模型不是训练完成就万事大吉，设备更新、数据来源变化和临床实践调整都可能影响模型表现，因此后续仍需定期复核和持续质量控制。

\subsubsection*{\textbf{6. 小结}}

医学影像识别通常由图像预处理、区域提取与图像分割、特征提取与特征表示、识别模型训练、结果输出与性能评价等环节组成。预处理改善图像质量并提高数据一致性，定位和分割明确目标区域，特征提取建立图像信息的表达方式，识别模型完成类别判断或异常提示，性能评价用于检验模型结果的稳定性和可靠性。不同影像类型和不同任务目标，对处理流程和识别方法提出不同要求。

\subsection{典型疾病的影像识别应用}

在医学影像人工智能应用中，不同疾病并不会使用完全相同的识别方法。肺结节检测需要在连续CT切片中寻找小病灶，眼底病变筛查需要从视网膜图像中识别出血和渗出，皮肤病变识别依赖皮肤镜图像中的颜色和边界特征，病理肿瘤分级需要在高分辨率切片中分析组织结构，心脏影像分析则关注心腔分割和功能参数计算。因此，医学影像识别不是简单地把图像交给模型分类，而是要根据疾病特点选择合适的检测、分割、分类和定量分析技术。

\subsubsection*{\textbf{1. 肺结节检测}}
肺结节是指肺部影像中出现的局灶性小阴影，可能与炎症、良性结节、早期肺癌或其他肺部病变有关。临床上，医生通常需要根据结节大小、密度、边缘形态、位置和随访变化判断其风险。肺结节检测主要面向低剂量计算机体层成像（low-dose computed tomography, LDCT）或常规胸部CT图像。一次胸部CT检查通常包含数百张连续切片，小结节可能只有几毫米，容易与血管截面、支气管壁或局部炎症影混淆。人工智能可以从三维CT数据中自动发现可疑结节位置，并为医生提供结节定位、大小测量和风险提示。

肺结节检测常使用三维卷积神经网络（3D CNN）和候选区域检测方法。3D
CNN能够同时利用相邻切片之间的空间连续信息，比只看单张二维图像更适合识别肺结节这类立体结构。实际模型通常先通过肺野分割去除胸壁、纵隔等无关区域，再在肺野内部提取可疑结节候选区域，随后利用分类网络判断候选区域是真正结节还是血管、伪影或其他正常结构。对于大小差异较大的结节，还可以使用多尺度特征融合，使模型同时关注小结节和较大病灶。模型输出通常包括结节位置框、结节直径、体积变化和恶性风险评分。肺结节检测通常需要从三维CT影像中完成肺野分割、候选区域提取、空间特征分析和风险结果输出，图9.8展示了肺结节AI检测从影像输入、肺野分割、候选区域提取、3D
CNN分析到结果输出和医生复核的基本过程。该流程说明，AI系统主要提供结节定位、大小测量和风险提示，最终判断仍需结合结节形态、随访变化和临床资料完成。需要注意的是，肺结节AI只能提供筛查和辅助判断，不能直接给出肺癌诊断，医生仍需结合结节边缘、密度、随访变化、吸烟史和病理结果综合判断。

\subsubsection*{\textbf{2. 眼底病变筛查}}
眼底病变是指发生在视网膜、视盘、黄斑和眼底血管等部位的异常改变，常见于糖尿病、高血压和部分眼科疾病。早期眼底病变可能没有明显视力下降，但眼底图像中已经出现出血、渗出、微血管瘤或新生血管等表现。眼底病变筛查主要使用眼底照相图像，常见任务包括糖尿病视网膜病变筛查、黄斑病变识别和视盘异常分析。眼底图像能够显示视网膜血管、视盘、黄斑和局部出血渗出等结构。对于糖尿病患者而言，早期视网膜病变可能没有明显视力下降，但图像中已经出现微血管瘤、出血点、硬性渗出或新生血管等改变。

眼底病变筛查常使用卷积神经网络（CNN）、迁移学习（transfer learning）和图像分类模型。CNN能够自动提取视网膜血管走行、出血点、渗出灶和黄斑区域等图像特征；迁移学习则可以利用已有自然图像或医学图像模型的基础特征，再针对眼底图像任务进行训练。部分系统还会结合病灶检测模型，对微血管瘤、出血和渗出区域进行定位，以便医生查看模型判断依据。模型输出通常包括是否存在病变、病变等级、是否需要转诊以及可疑区域提示。眼底病变筛查通常需要从眼底照相图像中完成图像预处理、病灶定位、特征提取、分类分级和转诊提示，其基本流程如图9.9所示。

\subsubsection*{\textbf{3. 皮肤病变识别}}
皮肤病变包括色素痣、脂溢性角化、基底细胞癌、黑色素瘤等多种类型，其中部分病变具有恶性风险。临床上，医生会观察病灶颜色、边界、形态、大小变化和局部结构，必要时结合皮肤镜检查或病理活检进行判断。皮肤镜能够放大观察皮肤表面的色素分布、边界形态、纹理结构和血管特征，常用于辅助判断色素痣、脂溢性角化、基底细胞癌和黑色素瘤等病变。

皮肤病变识别常采用深度卷积网络、EfficientNet模型和注意力机制。EfficientNet是一类在模型规模和识别性能之间进行平衡的卷积神经网络，适合用于皮肤镜图像分类。模型可以学习病灶颜色是否不均、边界是否规则、结构是否对称、局部纹理是否异常等图像特征。注意力机制可以使模型更加关注病灶区域，而不是被背景皮肤、尺标或图像边缘干扰。部分研究还会使用图像分割方法先提取病灶区域，再进行分类判断。模型输出通常包括病变类别、恶性风险概率和模型关注区域。图9.10展示了皮肤病变识别从皮肤镜图像输入、病灶分割、深度特征提取、注意力机制分析到分类判断和恶性风险评估的基本过程。该流程说明，人工智能可辅助识别色素痣、脂溢性角化、基底细胞癌和黑色素瘤等病变，并提供模型关注区域和风险提示；最终判断仍需结合病变变化时间、患者年龄、日晒史、家族史和必要的病理活检结果。

\subsubsection*{\textbf{4. 病理肿瘤分级}}
病理肿瘤分级是指根据肿瘤组织和细胞的形态特点，评估肿瘤分化程度、侵袭性和疾病严重程度的过程。病理医生通常需要观察细胞核形态、腺体结构、组织排列、染色特点和核分裂象等信息。病理肿瘤分级面向数字病理图像，尤其是全切片图像。全切片图像分辨率很高，一张图像可能包含大量组织区域和细胞结构。病理医生需要观察腺体结构、细胞核形态、核分裂象、染色深浅和组织排列方式，并据此进行肿瘤分类和分级。人工智能在病理肿瘤分级中的任务，是辅助识别肿瘤区域、区分组织类型，并为肿瘤分级提供参考。

数字病理AI常使用图像切块、多实例学习（multiple instance learning, MIL）、注意力机制和细胞检测方法。由于全切片图像太大，模型通常不能一次性处理整张图像，需要先把图像切成许多小块，再分别提取每个小块的特征。MIL可以把多个局部小块作为一个整体进行学习，使模型根据局部组织区域推断整张切片的诊断或分级结果。注意力机制可以帮助模型在大量小块中筛选更关键的肿瘤区域。对于需要分析细胞形态的任务，还可以使用细胞核分割和目标检测方法识别细胞核、腺体结构或肿瘤浸润区域。例如，在前列腺癌病理分级中，模型可辅助识别不同组织结构模式，并为Gleason评分提供参考。数字病理AI通常需要先对全切片图像进行切块处理，再结合局部特征提取、多实例学习、注意力机制和细胞检测等方法完成肿瘤区域识别与分级判断，其基本流程如图9.11所示。

\subsubsection*{\textbf{5. 心脏影像分析}}
心脏影像分析主要用于观察心脏结构和泵血功能，常服务于心力衰竭、心肌病、瓣膜病和心肌缺血等疾病评估。医生需要通过心脏超声、心脏磁共振成像或心脏CT观察心腔大小、室壁运动、瓣膜活动和心功能变化。与肺结节或皮肤病变不同，心脏影像不仅关注结构是否异常，还关注心脏在收缩和舒张过程中的动态功能。临床上常需要测量左心室容积、室壁运动、瓣膜活动和射血分数等指标，用于评估心力衰竭、心肌病、瓣膜病和心肌缺血等疾病。

心脏影像AI常使用U-Net分割模型、时序分析模型和自动定量计算方法。U-Net是一种常用于医学图像分割的编码器-解码器结构神经网络，可用于分割左心室、右心室、心肌和心腔区域。分割完成后，系统可以进一步计算心室面积、体积和射血分数（ejection fraction, EF）。对于心脏超声视频或动态磁共振图像，模型还需要分析连续帧之间的形态变化，从而识别收缩末期和舒张末期图像。部分系统会结合循环神经网络（RNN）或时序卷积模型处理动态影像序列。模型输出通常包括心腔分割轮廓、EF值、室壁运动异常提示和心功能评估结果。图9.12展示了心脏影像分析从心脏超声、心脏MRI和心脏CT输入，到图像预处理、心腔与心肌分割、动态时序分析、自动定量计算和综合分析输出的基本过程。该流程说明，人工智能可辅助完成心腔轮廓勾画、EF计算、室壁运动分析和心功能评估，但相关结果仍需医生结合切面质量、原始影像、心律情况和临床表现进行确认。

本节围绕肺结节检测、眼底病变筛查、皮肤病变识别、病理肿瘤分级和心脏影像分析五类任务，介绍了医学影像识别在典型疾病中的技术应用。肺结节检测常用3D
CNN和候选区域检测，眼底病变筛查常用CNN和迁移学习，皮肤病变识别常用EfficientNet和注意力机制，病理肿瘤分级常用图像切块、MIL和细胞检测，心脏影像分析常用U-Net分割和时序分析。不同技术对应不同医学问题，人工智能能够提供定位、分类、分割和定量参考，但其输出结果仍需结合图像质量、临床资料和医生复核进行判断。

\subsection{医学影像辅助诊断系统}

在医学诊疗中，影像检查常常是医生发现疾病线索的重要依据。过去，医生主要依靠肉眼观察X线片、CT图像或MRI图像，从图像中判断病灶位置、形态和范围，这种方式更接近“看图说话”的定性分析。随着医学影像逐渐数字化，图像不再只是供医生观察的胶片，也成为可以被计算机存储、测量和分析的数据。医学影像辅助诊断系统正是在这一基础上发展起来的，它通过图像处理和人工智能方法帮助医生发现可疑病灶、完成定量测量，并为临床诊断提供参考。

医学影像辅助诊断系统是指利用计算机图像处理、机器学习和深度学习等技术，对医学影像进行检测、分割、分类、测量和结果提示的信息系统。它的作用不是替代医生作出最终诊断，而是把影像中的关键信息以更清晰、更量化的方式呈现出来，帮助医生提高阅片效率和判断一致性。例如，在胸部CT图像中，系统可以提示疑似肺结节的位置；在心脏MRI图像中，系统可以辅助勾画心室边界，并计算心功能参数；在眼底图像中，系统可以筛查出疑似视网膜病变的患者。医学影像辅助诊断系统通常包括影像输入、数据接入、图像预处理、病灶检测、图像分割、特征提取、分类判断、定量测量、结果解释和医生复核等环节，其典型流程及疾病应用如图9.13所示。

\subsubsection*{\textbf{1. 影像数字化}}
医学影像辅助诊断系统的发展，离不开医学影像的数字化。传统X线摄影主要以胶片作为成像载体，医生通过观察胶片判断人体内部结构。随着计算机体层成像（CT）、磁共振成像（MRI）、计算机X射线摄影（computed radiography, CR）和数字X射线摄影（digital radiography, DR）等技术的出现，医学影像逐渐以数字图像形式保存和传输。数字化影像使图像可以被放大、调整窗宽窗位、进行三维重建，也为后续计算机分析提供了数据基础。

影像数字化改变了医学影像的使用方式。医生不再只能依赖胶片上的静态图像，而可以在工作站中查看连续切片、比较不同时间点影像、测量病灶大小，并调节图像显示参数。对于人工智能而言，数字化影像使模型能够直接读取图像像素、灰度、密度和空间结构，从而完成病灶识别、区域分割和定量分析。可以说，医学影像数字化是医学影像人工智能应用的前提。

\subsubsection*{\textbf{2. 辅助诊断系统}}
早期医学影像辅助诊断更多依赖计算机辅助检测和计算机辅助诊断。计算机辅助检测（computer-aided detection, CADe）主要用于发现图像中可能被医生漏看的异常区域，如肺结节、乳腺钙化点或骨折线。计算机辅助诊断（computer-aided diagnosis, CADx）则进一步对病灶性质或疾病类别进行判断，例如提示病灶良恶性风险或病变分级。CADe更强调“有没有、在哪里”，CADx更强调“是什么、风险多大”。

医学影像辅助诊断系统通常包括图像输入、预处理、模型分析、结果输出和医生复核几个环节。图像输入阶段，系统从影像归档与通信系统（PACS）中读取影像资料；预处理阶段，系统进行图像增强、配准、重采样和质量控制；模型分析阶段，系统利用检测、分割或分类模型识别病灶；结果输出阶段，系统用定位框、分割轮廓、概率评分、热力图或结构化报告呈现结果；医生复核阶段，医生根据原始影像和临床资料决定是否采纳系统提示。

\subsubsection*{\textbf{3. 核心分析技术}}
医学影像辅助诊断系统的核心技术包括图像分割、目标检测、图像分类和定量测量。图像分割用于划定器官、组织或病灶边界，例如肺野分割、肿瘤分割和心室分割。目标检测用于发现图像中可疑病灶的位置，例如肺结节检测、骨折检测和眼底出血点检测。图像分类用于判断图像或局部区域属于哪一类疾病状态，例如皮肤病变良恶性分类、眼底病变分级和病理肿瘤分级。定量测量则用于计算病灶直径、面积、体积、密度和心功能参数等指标，使影像判读从经验描述进一步走向数值化分析。

深度学习推动了医学影像辅助诊断系统的发展。卷积神经网络（CNN）能够从图像中自动学习边缘、纹理、形态和局部结构等特征，减少对人工设计特征的依赖。U-Net常用于医学图像分割，能够在保留局部细节的同时识别器官或病灶边界。三维卷积神经网络（3D CNN）适合处理CT和MRI等三维影像，能够利用连续切片之间的空间关系。注意力机制可以引导模型更加关注病灶区域或关键结构。对于动态心脏影像和内镜视频，还可以结合时序分析方法，观察器官结构和功能随时间变化的过程。

\subsubsection*{\textbf{4. 临床应用流程}}
医学影像辅助诊断系统进入临床时，需要嵌入医生实际阅片流程。以胸部CT肺结节筛查为例，系统首先读取CT图像，完成肺野分割和图像标准化处理；随后，检测模型在肺野内寻找可疑结节区域，并排除部分血管截面和伪影；最后，系统在阅片界面上标出结节位置，给出直径、体积、密度和风险提示。医生根据系统提示查看原始图像，再结合患者年龄、吸烟史、既往影像和临床资料进行判断。

以心脏MRI分析为例，系统可以自动识别左心室内外膜边界，计算心室容积和射血分数（EF）。这类功能可以帮助医生更快获得心功能参数，使影像分析从单纯观察室壁运动，进一步转向可量化的功能评价。图片中提到的心脏MRI分析软件通过监管批准，也说明医学影像辅助诊断系统要真正进入临床，不仅需要技术可行，还需要经过性能验证、质量控制和合规审查。

\subsubsection*{\textbf{5. 系统应用边界}}
医学影像辅助诊断系统能够提高阅片效率，也能减少部分重复测量工作，但它并不是独立诊断者。系统输出的定位框、分割边界、概率评分和风险提示，都是对图像特征的计算结果，不能直接等同于临床诊断结论。影像本身可能受到运动伪影、扫描参数、层厚差异、设备型号和患者配合程度影响，模型也可能受到训练数据来源和标注质量限制。

因此，医学影像辅助诊断系统必须由医生在临床语境中使用。医生需要判断模型标出的区域是否符合解剖结构和病变表现，也要结合患者症状、病史、实验室检查和其他影像资料进行综合分析。系统上线前应完成独立测试和外部验证，上线后还需要持续监测误报、漏报和医生反馈。当医院设备、成像协议或患者来源发生变化时，系统性能也应重新评估。医学影像辅助诊断系统的合理定位，是为医生提供更清晰、更量化和更高效的辅助信息，而不是把医学判断交给算法。

\subsubsection*{\textbf{6. 小结}}
本节介绍了医学影像辅助诊断系统的形成基础、系统组成、核心技术、临床流程和应用边界。医学影像数字化使图像能够被计算机存储、测量和分析，CADe和CADx推动影像分析从可疑区域提示走向病变性质判断，深度学习进一步提高了分割、检测、分类和定量测量能力。医学影像辅助诊断系统能够帮助医生提高阅片效率、完成定量分析和发现可疑病灶，但其结果仍需结合原始影像、临床资料和医生经验进行复核。

\subsection{辅助诊断结果与临床判读}

医学影像辅助诊断结果像是一份由模型生成的“阅片提示单”。它通常不直接等同于最终诊断结论，而是以图像标记、分类判断、定量参数或风险提示等形式呈现，为影像判读和临床综合分析提供参考。辅助诊断结果的价值，取决于它是否能够清楚表达图像中的关键异常，是否能够与原始影像和临床资料相互对应，是否便于医生在实际诊疗流程中理解和使用。如图9.14所示，辅助诊断结果通常包括定位、分割、分类、定量和提示性结果，不同结果形式对应不同临床判读重点。

\subsubsection*{\textbf{1. 辅助诊断结果的形成}}

辅助诊断结果通常由图像输入、模型分析和结果输出三个环节共同形成。原始医学影像经过预处理后进入识别模型，模型根据训练阶段形成的参数，对图像中的结构、纹理、密度、信号强度或空间分布等特征进行分析，并生成相应判断结果。病灶识别任务常输出可疑区域提示，图像分割任务输出器官、组织或病灶边界范围，分类任务输出类别标签或概率值，定量分析任务则输出长度、面积、体积、密度或变化幅度等数值信息。

辅助诊断结果的形成依赖于模型所学习到的影像特征。传统机器学习方法通常根据人工提取的灰度、纹理、形状和统计特征进行判断，深度学习方法则通过卷积神经网络、注意力机制或多模态融合模型自动学习影像特征。不同方法得到的输出形式可能存在差异，但都需要回到原始影像中进行核对。对于医学影像判读而言，系统输出不能脱离图像本身，也不能脱离检查部位、扫描参数和患者临床背景。

\subsubsection*{\textbf{2. 结果类型与表达方式}}

辅助诊断结果可以分为定位结果、分割结果、分类结果、定量结果和提示性结果等类型。定位结果主要用于指出图像中需要关注的可疑区域，常见表现形式包括标记框、中心点、热力图和重点区域提示。分割结果则用于描绘器官、组织或病灶边界，通常以轮廓线、区域掩膜或彩色叠加图的形式显示。定位结果偏向发现位置，分割结果偏向明确范围，二者在影像分析中常相互衔接。

分类结果主要用于表达模型对某一影像对象所属类别的判断，例如正常与异常、良性与恶性、轻度与重度等。分类结果常与概率值或置信度一同显示，用于提示模型对该判断的确定程度。定量结果则将影像信息转化为可比较的数值指标，包括病灶直径、面积、体积、密度、信号强度、摄取值和变化比例等。提示性结果通常综合定位、分类和定量信息，以文字、分级或风险提示的形式呈现。良好的辅助诊断结果应当具有清晰的位置对应、明确的结果含义和相对直观的表达形式，便于医生结合原始影像进行复核。

\subsubsection*{\textbf{3. 临床判读的基本要求}}

医生面对模型输出时，需要做的不是简单接受，而是进行医学解释。人工智能系统可以标出可疑区域、给出概率评分或生成分割轮廓，但这些结果仍需放在完整临床语境中理解。影像异常的性质判断，通常需要结合患者年龄、症状体征、既往病史、实验室检查、其他影像资料及随访变化。单一影像结果或单一模型输出，难以完整反映疾病状态。

在实际判读中，医生需要同时关注系统结果与原始影像之间的一致性。若系统标出的可疑区域与影像表现相符，可进一步分析其形态、边界、密度、信号和位置特点；若系统结果与医生观察存在差异，则需要重新检查图像质量、扫描参数、病灶表现和模型可能产生误判的原因。对于分割结果，还需要观察边界是否准确，是否存在漏分割或过度分割；对于分类结果，需要判断类别标签是否与影像特征和临床资料一致；对于定量结果，需要关注测量范围是否正确，数值变化是否具有医学解释意义。

\subsubsection*{\textbf{4. 结果可靠性与使用边界}}

辅助诊断结果的可靠性受多种因素影响。影像质量、标注质量、训练数据来源、模型结构、样本数量和疾病类型都会影响输出结果。图像噪声、伪影、扫描层厚、成像序列差异和设备参数变化，可能导致模型识别能力下降。若训练数据来源较单一，模型在其他医院、其他设备或不同人群数据上的表现也可能发生变化。医学影像人工智能模型在使用前通常需要经过验证，常见评价指标包括敏感度、特异度、准确率、F1值、受试者工作特征曲线下面积、Dice系数和交并比等。

辅助诊断结果应作为医学判读的参考信息，而不应替代完整的临床诊断过程。系统输出可以提高图像分析效率，减少部分重复性工作，也可以提示容易遗漏的可疑区域，但最终诊断仍需由医生结合完整资料作出。对于边界病例、少见病变、图像质量较差或临床表现不典型的情况，系统结果更需要谨慎复核。辅助诊断的使用边界越清晰，越有利于发挥其在影像分析中的作用，也能减少过度依赖模型结果带来的误判风险。

\subsubsection*{\textbf{5. 小结}}

辅助诊断结果是医学影像人工智能分析过程的输出形式，常见类型包括定位结果、分割结果、分类结果、定量结果和提示性结果。临床判读需要将这些结果与原始影像、检查参数和患者临床资料结合起来分析。辅助诊断系统能够提供结构化、可视化和定量化的信息，但其结果仍需经过医学解释和人工复核。

\section{临床决策分析与健康管理}

临床决策分析与健康管理，关注的是诊断之后还要继续发生的事情。患者的病历记录、检验指标、医学影像、生理信号、用药记录和随访信息，能够从不同方面反映疾病状态、治疗反应和健康变化。通过机器学习、深度学习、时间序列分析和知识推理等方法，人工智能可以对多源临床数据进行整合分析，用于风险预测、疗效评估、个体差异分析和方案支持。与单次诊断判断不同，临床决策分析更强调多因素综合判断，健康管理则更关注长期监测、动态评估和持续干预。

在实际应用中，人工智能通常以电子病历、检验检查、医学影像、生理信号、用药记录和随访信息等多源数据为基础，对患者风险、治疗反应、个体差异和管理方案进行连续分析，并通过反馈调整支持后续诊疗与健康管理，如图9.15所示。

\subsection{临床风险预测与疗效评估}

临床医生常常需要回答两个连续问题：患者未来风险有多高，当前治疗是否真的有效。临床风险预测与疗效评估分别面向这两个连续问题。风险预测关注患者未来可能出现的不良事件、病情变化或结局差异；疗效评估关注治疗或干预后患者状态是否改善、改善程度如何以及这种变化是否具有医学意义。二者都依赖既往资料、当前状态和随访数据，具有明显的时间维度和多因素特征。人工智能方法在这一部分的作用，主要体现在变量整合、模式学习、风险分层和效果评价等方面。如图9.16所示，临床风险预测与疗效评估包括预测目标设定、变量构建、模型训练、性能评价和结果反馈等关键步骤。

\ChNineFigure{./images_chapter_07-08/9.16.png}{临床风险预测与疗效评估流程示意图}{fig:ch9_16}

\subsubsection*{\textbf{1. 风险预测的含义}}
风险预测依据患者已有信息，对未来某一时间范围内可能发生的临床事件进行估计，预测对象可以是疾病发生、病情进展、并发症出现、再入院、复发、死亡或其他临床结局。与一般分类任务相比，风险预测更强调时间关系和结局发生概率，需要把患者当前状态与未来事件联系起来。

风险预测通常需要明确三个基本要素。第一是预测对象，即模型需要预测什么事件。第二是预测时间窗，即事件发生的观察范围。第三是输入变量，即用于预测的患者信息。输入变量可以包括人口学信息、病史资料、检验指标、影像特征、用药记录、生理监测数据和随访结果。预测模型的输出一般表现为风险概率、风险等级或预警提示。

在方法上，风险预测既能采用传统统计模型，也可以采用机器学习和深度学习模型。传统方法如逻辑回归和Cox比例风险模型，适合解释变量与结局之间的关系。机器学习方法如随机森林、支持向量机、梯度提升树和XGBoost，适合处理多变量、非线性和变量间交互关系。对于连续监测数据和多时点随访数据，可采用循环神经网络、长短期记忆网络、时序卷积网络和Transformer模型进行时间序列建模。

\subsubsection*{\textbf{2. 预测变量与数据处理}}
建立风险预测模型时，变量不是越多越好。真正有价值的预测变量应与预测目标具有明确关联，并具有稳定的记录来源。常见变量包括年龄、性别、既往病史、生命体征、实验室检查结果、影像特征、治疗记录和随访指标等。影像数据可提取病灶大小、密度、体积、纹理和空间分布等信息；生理信号数据可提取心率变异性、波形特征、频域特征和动态变化趋势等信息。

数据构建通常包括样本筛选、时间窗设定、结局标注和变量整理。样本筛选用于明确纳入和排除标准，保证研究对象与预测目标一致。时间窗设定用于区分模型输入期和结局观察期，避免把结局发生后的信息错误纳入预测变量。结局标注需要依据明确标准确定事件是否发生。变量整理则包括缺失值处理、异常值检查、单位统一和连续变量归一化等。

在临床预测任务中，数据分布不平衡较为常见。例如，某些不良事件发生比例较低，模型容易偏向多数类别。针对这种情况，可采用重采样、类别权重、阈值调整或代价敏感学习等方法。对于随访时间不一致或存在删失数据的任务，则需要采用生存分析或相应的时间结局建模方法。

\subsubsection*{\textbf{3. 模型构建与性能评价}}
风险预测模型的训练过程通常包括数据划分、特征选择、模型建立、参数优化和性能验证。数据可划分为训练集、验证集和测试集。训练集用于模型学习，验证集用于参数调整，测试集用于评价模型在未见数据上的表现。若条件允许，还应采用外部验证数据，以观察模型在不同机构、不同设备或不同人群中的稳定性。

不同模型适用于不同任务。逻辑回归适合二分类风险预测，模型结构清楚，结果较易解释。Cox模型适合包含随访时间的生存结局分析。随机森林和梯度提升树能够处理非线性关系和变量交互，对结构化临床数据具有较好适应性。深度学习模型适合处理高维影像、病历文本和连续监测数据，但对样本量、标注质量和计算资源要求更高。

模型评价需要根据任务类型选择合适指标。分类预测常用准确率、敏感度、特异度、精确率、F1值和受试者工作特征曲线下面积。生存预测常用一致性指数和校准曲线。风险预测模型还需要关注校准能力，即模型给出的风险概率是否与真实发生率相符合。医学场景中的模型评价不能只看单一指标，需结合临床目标判断模型是否适合用于风险分层和预警分析。

\subsubsection*{\textbf{4. 疗效评估的基本方法}}
疗效评估关心的是治疗之后发生了什么变化。它通过比较治疗或干预前后的患者状态，分析症状是否改善、指标是否变化、影像是否好转、功能是否恢复、并发症是否减少或生活质量是否提高。疗效评估不只关注是否有效，还关注疗效大小、持续时间和个体差异。人工智能方法可用于整合多时点数据，识别疗效相关特征，并辅助判断治疗后的变化趋势。

疗效评估通常需要明确评价指标、观察时间点和对照方式。评价指标应与疾病特点和治疗目标相匹配，可以是实验室指标、影像参数、生理信号、功能评分或复合结局。观察时间点用于判断疗效变化的过程性，如治疗前、治疗中、治疗后和随访阶段。对照方式可包括自身前后比较、组间比较或基于真实世界数据的匹配比较。

在方法上，疗效评估可采用统计分析、机器学习和因果推断等方法。传统统计方法适合比较治疗前后指标变化和组间差异。机器学习方法可用于预测疗效反应，识别对治疗敏感或不敏感的人群。倾向评分匹配、逆概率加权和因果森林等方法可用于降低混杂因素影响，辅助分析治疗与结局之间的关系。对于影像和连续监测数据，还可结合图像特征变化和时间序列变化，构建多维疗效评价模型。

\subsubsection*{\textbf{5. 小结}}
临床风险预测与疗效评估是人工智能参与临床分析的重要基础。风险预测通过患者当前信息和历史数据估计未来结局，疗效评估通过多时点数据分析治疗或干预后的状态变化。前者强调概率估计、风险分层和预警提示，后者强调指标变化、效果判断和个体反应。常用方法包括逻辑回归、Cox模型、随机森林、梯度提升树、深度学习时序模型和因果推断方法等。二者共同构成从风险识别到效果反馈的分析过程，为后续诊疗方案支持和健康管理提供方法基础。

\subsection{临床决策支持与诊疗路径}

一名老年患者因胸闷、气短到急诊就诊，医生需要在较短时间内判断患者是否存在急性冠脉综合征、心力衰竭、肺部感染或其他疾病。病历中记录了患者既往高血压和糖尿病史，心电图提示部分导联异常，肌钙蛋白和脑钠肽指标正在等待结果，胸部影像还需要结合临床表现进一步判断。面对这类复杂情况，医生并不是只根据某一项检查作出决定，而是需要把症状、体征、检验指标、影像资料、既往病史和诊疗指南放在一起分析。临床决策支持与诊疗路径，正是人工智能进入临床诊疗流程的重要方式之一。

临床决策支持系统（clinical decision support system, CDSS）是指利用患者数据、医学知识和计算模型，为医生提供诊断提示、风险提醒、检查建议、用药警示和治疗方案参考的信息系统。它的核心作用不是替代医生做决定，而是帮助医生在复杂信息中更快发现关键线索，减少遗漏和不合理选择。诊疗路径是围绕某类疾病或临床问题形成的诊断、检查、治疗和随访流程。人工智能可以把患者当前状态与诊疗路径进行匹配，提示下一步检查、治疗重点和风险管理要求。临床决策支持系统通常需要整合患者数据、医学知识库、诊疗指南和历史病例信息，并通过诊疗路径匹配形成诊断提示、风险提醒、检查建议和治疗方案参考，其基本流程如图9.17所示。

\subsubsection*{\textbf{1. 临床决策支持}}
临床决策支持关注医生在诊疗过程中如何获得更及时、更清晰的辅助信息。患者进入医院后，系统可以从电子病历、检验检查、医学影像和用药记录中提取关键内容，并结合疾病知识、诊疗指南和历史病例，为医生提供结构化提示。例如，对于疑似心肌梗死患者，系统可以结合胸痛时间、心电图表现、肌钙蛋白水平和危险因素，提示患者是否需要进一步急诊处理；对于肾功能异常患者，系统可以在开具某些药物时提醒医生注意剂量调整。

临床决策支持并不意味着系统给出一个固定答案。更准确地说，它提供的是一组经过整理的信息和建议，包括可能诊断、风险等级、检查建议、用药提醒和随访要求。医生仍然需要结合患者具体情况判断这些建议是否适用。对于症状不典型、合并疾病较多或检查结果相互矛盾的患者，系统提示只能作为参考，最终判断必须由医生完成。

\subsubsection*{\textbf{2. 知识库与规则}}
临床决策支持系统通常需要医学知识库作为基础。医学知识库是指将疾病、症状、检查、药物、治疗方案和临床指南等医学知识进行结构化整理后形成的知识资源。它可以帮助系统理解不同医学概念之间的关系，例如“胸痛”可能与心肌缺血、肺栓塞、主动脉夹层或胃食管反流等多种问题有关，“肾功能下降”会影响某些药物的使用剂量和用药安全。

规则库是医学知识库中的常见形式。规则库通常把医学经验和指南要求表达为明确的判断规则。例如，若患者对青霉素过敏，系统在相关药物开具时给出警示；若糖尿病患者糖化血红蛋白长期升高，系统提示加强血糖管理和并发症筛查。规则库的优势是逻辑清楚、结果容易解释，适合用于用药提醒、危急值提示和诊疗流程检查。但规则库也有局限，面对复杂病例或多病共存患者时，固定规则可能覆盖不足，需要结合模型预测和医生判断。

\subsubsection*{\textbf{3. 知识图谱}}
知识图谱（KG）是一种用节点和关系表示知识结构的方法。在医学场景中，节点可以表示疾病、症状、药物、检查项目、病原体、治疗方案和不良反应，关系则表示它们之间的联系。例如，“感染病”可以与“细菌”\,“病毒”\,“抗生素”\,“病原学检查”\,“发热”等节点相连；“糖尿病”可以与“血糖升高”\,“糖化血红蛋白”\,“二甲双胍”\,“糖尿病肾病”等节点相连。通过这种结构，系统能够把分散的医学知识组织成相互关联的网络。

知识图谱适合用于专业知识要求较高的子领域服务。以感染病诊疗为例，系统可以围绕病原体、感染部位、药物敏感性、抗菌药物和用药禁忌建立知识关联。当患者出现发热、白细胞升高和肺部影像异常时，系统可结合病原学检查、既往用药、基础疾病和抗菌药物规则，提示可能的感染类型和用药注意事项。由于感染病和抗生素使用对专业知识、药物规则和系统稳定性要求较高，相关系统通常需要将知识图谱与专家规则结合使用，而不能只依赖模型自动生成结论。

知识图谱也可用于辅助问诊、疾病鉴别、检查推荐和用药提醒。以咳嗽患者为例，系统可以根据咳嗽持续时间、发热、痰液性质、胸部影像和既往疾病，把肺部感染、哮喘、慢性阻塞性肺疾病和肺部肿瘤等可能情况进行关联分析。对于肿瘤患者，知识图谱还可以把病理类型、基因突变、药物靶点和治疗方案连接起来，为个体化治疗提供参考。需要注意的是，知识图谱中的知识需要持续更新，否则可能无法反映最新指南和临床证据。

\subsubsection*{\textbf{4. 诊疗路径}}
诊疗路径是将疾病诊疗过程按照一定顺序组织起来的流程化方案，通常包括初步评估、必要检查、诊断判断、治疗选择、疗效观察和随访管理等环节。对于常见病和慢性病，规范化诊疗路径有助于减少漏检、重复检查和不合理治疗。人工智能可以根据患者数据判断其所处的诊疗阶段，并提示下一步需要关注的内容。

以糖尿病管理为例，诊疗路径通常包括血糖评估、生活方式干预、药物治疗、并发症筛查和长期随访。系统可以根据患者空腹血糖、糖化血红蛋白、肾功能、体重和用药情况，提示是否需要调整治疗方案，是否需要进行眼底检查、尿蛋白检测或心血管风险评估。以脑卒中急诊处理为例，系统可以根据发病时间、影像检查、凝血功能和禁忌证信息，提示是否进入进一步评估流程。诊疗路径的价值在于让复杂诊疗过程更清晰，但它不能机械套用到每一名患者身上，合并症、禁忌证和个体差异都需要医生重新判断。

\subsubsection*{\textbf{5. 技术方法}}
临床决策支持系统常结合规则推理、机器学习、自然语言处理和知识图谱等技术。规则推理适合处理明确、稳定的医学规则，如药物禁忌、过敏提醒和危急值提示。机器学习可以从历史病例中学习患者特征与诊断结果、风险结局或治疗反应之间的关系，用于风险预测、疗效评估和疾病分型。自然语言处理（NLP）可以从病历文本、检查报告和出院小结中提取症状、诊断、药物和时间信息。知识图谱则用于组织医学概念之间的关系，使系统能够在疾病、检查、药物和治疗方案之间建立联系。

在实际系统中，这些技术往往不是单独使用。一个抗菌药物决策支持系统可以同时使用知识图谱、专家规则和患者检验指标，辅助判断药物选择和用药风险；一个肿瘤诊疗支持系统可以结合病理报告、基因检测结果、影像分期和知识图谱；一个慢病管理系统可以同时分析结构化指标、随访文本和可穿戴设备数据。技术组合越复杂，系统越需要清晰解释输出依据，否则医生很难判断建议是否可靠。

\subsubsection*{\textbf{6. 应用边界}}
临床决策支持系统能够提高信息整合效率，但不能替代医生承担完整诊疗责任。系统可能受到数据缺失、规则更新滞后、模型偏差和知识库覆盖不足的影响。例如，患者的某项关键检查尚未完成，系统给出的建议可能并不充分；某些罕见病或复杂合并症不在知识库覆盖范围内，系统提示也可能不准确。对于急危重症和高风险治疗决策，医生必须结合现场观察、患者意愿和临床经验进行综合判断。

临床决策支持还需要注意过度提醒问题。如果系统频繁弹出低价值提示，医生可能产生提醒疲劳，反而忽略真正重要的风险警示。因此，系统设计应突出高风险、高价值和可操作的信息，而不是把所有规则都机械推送给医生。人工智能进入诊疗路径后，应服务于临床工作流程，使医生更容易获得关键线索，而不是增加额外负担。

\subsubsection*{\textbf{7. 小结}}
本节介绍了临床决策支持与诊疗路径的基本内容。临床决策支持系统通过整合患者数据、医学知识和智能模型，为医生提供诊断提示、风险提醒、检查建议、用药警示和治疗方案参考；诊疗路径则把疾病诊断、治疗和随访管理组织为相对清晰的流程。知识图谱能够把疾病、症状、检查、药物和治疗方案组织成关联网络，专家规则能够提高系统在专业子领域中的稳定性和可解释性。规则库、知识图谱、机器学习和自然语言处理等技术能够支持临床信息整理和辅助判断，但系统结果仍受数据质量、知识更新、模型偏差和临床语境影响。

\subsection{个体诊疗管理与健康干预}

慢病管理中，两位诊断相同的患者，可能因为年龄、基础疾病、生活方式、治疗反应和随访依从性不同，走向完全不同的病程。个体诊疗管理与健康干预是临床分析结果进一步转化为持续服务的过程。它不能只依据单一指标或单次检查结果作出判断，而需要综合病史资料、检验结果、影像信息、生理监测数据、用药记录和随访信息，形成较完整的个体状态描述。人工智能在这一过程中主要用于个体特征整理、患者分层、方案辅助匹配、干预过程监测和效果反馈分析，并进一步形成持续更新的个体诊疗管理闭环，其基本过程如图9.18所示。

\subsubsection*{\textbf{1. 个体诊疗管理的基本含义}}
个体诊疗管理强调把患者当作持续变化的个体来理解。它是指根据患者具体疾病状态、身体条件和治疗反应，对诊疗过程进行持续分析和管理。与一般诊疗流程相比，个体诊疗管理更重视患者之间的差异，也更强调诊疗过程的连续性。疾病类型、严重程度、合并症情况、既往治疗反应、用药史和生活习惯等因素，都会影响治疗方案选择和后续管理方式。

在人工智能处理中，个体诊疗管理通常需要先建立患者画像。患者画像并不是简单记录姓名、年龄等基本信息，而是将病历、检验、影像、用药、监测和随访等多类数据进行整合，形成对患者当前状态和变化过程的结构化描述。常见内容包括疾病特征、风险水平、治疗反应、依从性情况和随访状态等。患者画像建立后，系统可以进一步开展患者分层、相似病例匹配和方案辅助分析。

个体诊疗管理的核心在于从群体规律中提取可用于个体判断的信息。临床研究通常提供人群层面的证据，而具体患者可能受到多种因素共同影响。人工智能方法可以在大量历史数据中识别不同患者群体的特征差异，并将这些差异与治疗反应、风险水平和管理需求联系起来，为后续诊疗支持提供基础。

\subsubsection*{\textbf{2. 个体差异与数据基础}}
个体差异是开展个体诊疗管理的重要依据。患者之间的差异既包括年龄、性别、体重、基础疾病和遗传背景等相对稳定的信息，也包括生命体征、检验指标、影像表现、症状变化和用药反应等动态信息。不同类型数据反映的侧重点并不相同，结构化临床数据适合描述基本状态和指标水平，医学影像适合反映组织结构和病灶变化，生理信号适合记录连续状态，随访数据则能够反映治疗后变化和长期管理情况。

在数据处理过程中，个体差异分析通常需要完成多源数据整合、变量筛选和特征表示。多源数据整合用于将分散在不同系统中的患者信息连接起来，变量筛选用于识别与疾病状态或治疗反应相关的关键因素，特征表示则将患者状态转化为模型可以处理的数据形式。常用方法包括统计分析、聚类分析、降维方法、特征选择、表示学习和多模态融合等。

患者分层是个体差异分析中的常见任务。通过聚类分析、决策树、随机森林、梯度提升树或深度学习模型，可以根据患者特征将其划分为不同风险层级或不同反应类型。分层结果并不等同于最终治疗方案，但可以帮助识别哪些患者需要更密切监测，哪些患者可能对某类干预更敏感，哪些患者存在较高风险或较低依从性。患者分层使诊疗管理从平均化处理逐步转向差异化管理。

\subsubsection*{\textbf{3. 方案支持与方法路径}}
方案支持要解决的是“下一步怎么做”这一临床问题。它的目标是根据患者状态和已有医学知识，为诊疗方案选择、干预强度调整和随访安排提供参考。方案支持并不是自动替代临床决策，而是将患者数据、医学知识和历史经验进行综合分析，形成可供医生判断的辅助信息。

常用方法主要包括规则推理、知识图谱、机器学习和推荐模型等。规则推理适用于诊疗路径明确、判断条件较清楚的任务，可以根据临床指南、专家经验或管理规范进行条件匹配。知识图谱适合组织疾病、症状、检查、药物、治疗方式和结局之间的关系，能够为方案支持提供结构化知识基础。机器学习方法则可利用历史病例数据建立患者特征与治疗反应之间的关联模型，常见方法包括逻辑回归、随机森林、支持向量机、梯度提升树和神经网络等。对于需要连续调整的管理过程，也可采用强化学习或动态优化方法，对不同时间点的状态变化和干预反馈进行建模。

方案支持的一般步骤包括患者状态表示、候选方案生成、方案适配分析和结果输出。患者状态表示用于描述患者当前疾病状态和风险水平；候选方案生成可以来自临床规则、知识库或历史病例；方案适配分析用于比较不同方案与患者特征之间的匹配程度；结果输出通常表现为方案排序、风险提示、注意事项或随访建议。该过程需要保留人工复核环节，使输出结果能够与临床经验和实际条件相衔接。

\subsubsection*{\textbf{4. 健康干预与过程监测}}
健康干预把诊疗管理从医院延伸到日常生活。许多疾病的管理并不止于一次诊断或一次治疗，而需要围绕生活方式调整、用药依从性、康复训练、指标监测和定期随访等内容持续进行。健康干预关注患者状态变化和行为管理过程，重点在于及时发现异常变化，并根据反馈信息调整管理策略。

人工智能在健康干预中的方法基础包括时间序列分析、异常检测、行为识别、风险预警和个体化提醒等。可穿戴设备、移动健康平台和远程监测系统可以持续记录心率、血压、血糖、活动量、睡眠和康复训练情况等信息。时间序列模型可用于分析指标变化趋势，异常检测模型可用于发现偏离正常模式的状态变化，风险预警模型可用于提示需要关注的风险信号。对于干预提醒和随访管理，还可结合规则模型和推荐模型，根据患者状态推送相应的复查、用药、运动或生活方式建议。

过程监测要求数据具有连续性和可追踪性。单次测量结果只能反映某一时点的状态，连续监测更有助于观察变化趋势和干预效果。人工智能方法在处理这类数据时，需要关注数据缺失、设备误差、个体基线差异和异常波动等问题。稳定的过程监测结果，可以为长期健康管理提供动态依据。

\subsubsection*{\textbf{5. 反馈评价与动态调整}}
治疗方案实施后，真正的问题变成：患者是否变好了，原有方案是否还合适。个体诊疗管理和健康干预都需要反馈评价，将干预前后的信息进行对比，分析症状、检验指标、影像表现、生理状态和生活质量是否发生改善，风险水平是否下降，原有方案是否需要调整。

反馈评价通常包括指标变化分析、疗效反应判断、依从性评估和风险重新分层。指标变化分析可采用统计比较、趋势分析和时间序列建模等方法；疗效反应判断可结合机器学习模型识别对某类方案反应较好的患者特征；依从性评估则可结合用药记录、随访记录和设备监测数据进行分析。风险重新分层用于根据最新数据更新患者状态，使管理过程从静态判断转向动态调整。

患者状态变化后，管理方案也需要随之调整。动态调整是个体诊疗管理的重要特征，原有风险等级、干预强度和随访计划可能需要重新评估。人工智能系统可以将新的监测数据和反馈结果纳入模型，更新患者画像和风险判断，并为下一阶段管理提供参考。这个过程不是一次性完成的，而是在持续数据积累和反复反馈中不断修正，有助于提高管理的连续性和针对性。

\subsubsection*{\textbf{6. 小结}}
个体诊疗管理与健康干预以患者差异和连续状态变化为基础，强调从多源数据中形成个体化状态描述，并据此开展患者分层、方案支持、过程监测和效果反馈。常用方法包括特征选择、聚类分析、机器学习预测模型、知识图谱、规则推理、时间序列分析和异常检测等。个体诊疗管理侧重诊疗过程中的方案支持和风险调整，健康干预侧重院外监测、行为管理和长期随访。二者共同构成从临床判断到持续管理的衔接环节，为人工智能参与医学服务提供了重要方法基础。

\section*{本章小结}

本章围绕人工智能赋能医学的应用基础展开，介绍了医学数据基础、医疗人工智能典型任务、医学影像识别与辅助诊断，以及临床决策分析与健康管理等内容。在医学数据方面，电子病历、检验指标、医学影像、生理信号、生命组学数据和健康监测数据共同构成了医学人工智能的重要基础，但这些数据来源分散、形式多样，进入模型分析前需要经过采集、清洗、标注和标准化处理。在典型任务方面，人工智能可用于病灶识别、辅助诊断、风险预测和治疗决策支持，帮助医生从复杂数据中发现异常线索、判断疾病状态并评估未来风险。在医学影像应用方面，不同影像类型具有各自的成像特点和临床用途，人工智能通过图像预处理、分割、特征提取和模型识别等步骤，为辅助诊断提供定量化和可视化支持。在临床决策与健康管理方面，人工智能进一步延伸到风险评估、疗效分析、患者分层和个体化干预等环节，推动医学服务从单次判断走向连续管理。综上所述，医学人工智能要真正进入医学应用，不能只依靠模型本身的性能，还需要明确数据来源、任务目标、结果含义和使用场景。数据为模型提供基础，医学知识为结果解释提供依据，临床流程则决定人工智能结果能否被正确使用。
